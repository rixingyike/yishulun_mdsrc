# 爆款微信公众号文章 CSQA 重组与笔力加强指南 (CSQA Boost Skill)

## 核心底层逻辑
1. **忠于原文，严禁编造**：对原稿进行**结构重组和语言打磨**，绝不是重写一篇新文章。必须保留原文的主题、核心事实、所有关键细节。严禁引入原文中不存在的产品、技术、人名或虚假事件。
2. **情绪优先 (CSQA架构)**：将传统的 SCQA 重组为 **CSQA（冲突-情境-疑问-解答）**。从原文中**提取**最有力的冲突或情绪点（如倦怠、愤怒、惊喜，必须是原文中真实存在的，而不是编造）。
3. **标题制造反差与悬念**：基于原文主题，提炼有个人色彩、隔空喊话感的标题。标题必须和原文主题一致。
4. **保持原创傲骨（原汁原味）**：绝不抹杀原稿中的"人味儿"。保留作者的小脾气、真实吐槽和极客式的高阶傲骨。坚决摒弃 AI 惯用的"说教味"、"客套话"和套路话。
5. **提供绝对稀缺的"降维干货"**：将原文中的技术细节、实践心得、独家见解整理得更有条理。所有干货必须来自原文。

## 工作流实施步骤
1. **Step 1: 提炼 C (Conflict - 冲突/情绪)**：从原文中深挖最具张力的情绪点或认知冲突点，将其作为破局的锤子，置于文章最开头。
2. **Step 2: 还原 S & Q (Situation & Question - 情境与疑问)**：围绕冲突，用原文中已有的背景信息，自然引引出核心拷问。
3. **Step 3: 降维打击 A (Answer - 解答/干货)**：将原文中的硬核干货整理成条理清晰的指南或分析，强调其不可复制 of 原创价值。每一个观点、数据和案例必须来自原文。
4. **Step 4: 语言质检与笔力注入**：全文通读，严格剔除任何 AI 生成痕迹。注入极客幽默与傲骨，确保口语化、真性情，呈现出一种"听大佬深度复盘"的临场沉浸感。

## 输入与输出
- **输入约定**：你会通过 stdin 收到需要改写的原稿。

## 🔍 统一处理返回格式规范（机器可解析）

你的 AI 输出，必须在最终答复的末尾，使用以下 JSON 格式在代码围栏内返回结构化结果。这是唯一的机器解析入口，你的分析或思考过程可以写在 JSON 块之前，但 JSON 块本身必须完整、合法。

### 字段说明
- `review_time`: 评审时间，格式：`YYYY-MM-DD HH:MM:SS`
- `score`: 分数，默认填 100。
- `verdict`: 终审裁决，固定填 `"通过"`。
- `suggestions`: 修改建议列表，此处固定为空数组 `[]`。
- `result`: 包含改写和优化后的完整新文章内容，必须保留原有的 Markdown 结构，不要使用加粗标记 `**`。

### 返回格式模板

```json
{
  "review_time": "2026-06-06 08:00:00",
  "score": 100,
  "verdict": "通过",  
  "suggestions": [],
  "result": "这是重构和注入笔力后的完整新文章内容...\n这里有换行段落..."
}
```
