# 短动态闲言 (Tweets) 发布指南

在技术长文与系统专栏之外，创作者每天都会产生许多碎片化的灵感、阅读摘录、开发随笔或生活剪影。如果每条都写成正式博文，心理负担太重；如果只发在第三方社交平台，数据无法完全沉淀在自己的独立站点上。

RustPress 创新性地内建了 **短动态系统（Tweets / 闲言）**，为您提供完全去中心化、自主掌控的个人微语录。

---

## 一、Tweets 目录组织规范

短动态在 `source/tweets/` 目录下按「年份 / 月份」层级自动归档：

```text
source/tweets/
└── 2026/
    └── 08/
        ├── assets/                   # 当月动态专属配图
        │   ├── 20260828143000_0.jpg
        │   └── 20260828143000_1.jpg
        └── 20260828143000.md         # 动态文件（以发布时间戳命名）
```

---

## 二、单条动态 Markdown 格式规范

每条动态是一个轻量级的 Markdown 文件：

```yaml
---
date: 2026-08-28 14:30:00
layout: tweet
images:
  - "/tweets/2026/08/assets/20260828143000_0.jpg"
  - "/tweets/2026/08/assets/20260828143000_1.jpg"
---

今天把 RustPress 的增量编译机制重构了一遍，毫秒级响应带来的流畅感真的让人欲罢不能。静态博客的终局，就应该是极简、极速与彻底的数据掌控！
```

### 属性说明
- **`date`**：发布时间戳，用于时间轴精准排序。
- **`layout: tweet`**：指示模板采用微动态流卡片样式渲染。
- **`images`**：可选配图列表数组，支持相对路径或外部图床链接。

---

## 三、多图智能九宫格排版

RustPress 主题模板针对 `images` 图片数量提供了自适应视觉呈现：
- **单张图片**：自适应大图展示，保持原始宽高比。
- **两张图片**：优雅的双列并排对齐。
- **三张及以上（3 / 4 / 9 图）**：自动转换为自适应正方形网格（九宫格），支持点击调用 Lightbox 灯箱查看高清原图。

---

## 四、一键发布动态（CLI 指令、辅助脚本与 HTTP API）

RustPress 为发布微动态提供了三种极其便捷的姿势：

### 1. 终端命令行快速发布（推荐）
```bash
# 使用 RustPress CLI 子命令
rustpress new-tweet "今天完成了 RustPress CLI 指令扩展，写作体验又上一层楼！"

# 或使用辅助脚本
./new-tweet.sh "今天完成了 RustPress CLI 指令扩展，写作体验又上一层楼！"
```
**自动化处理**：系统会自动按当前年份与月份创建子目录（`source/tweets/YYYY/MM/`），并以时间戳自动命名（如 `20260830193000.md`），自动写入 `layout: tweet`。

---

### 2. 本地极速多媒体发布 API（带配图一键上传）
当本地开发服务器（`rustpress serve`）运行时，系统内建了极简的 HTTP 上传端点：

- **接口地址**：`POST http://localhost:1111/api/tweets`
- **请求类型**：`multipart/form-data`
- **参数说明**：
  - `text`：动态文字内容（支持 Markdown）
  - `images`：上传的配图文件（支持多选）

#### 终端配图一键发布命令示例（curl）
```bash
curl -X POST http://localhost:1111/api/tweets \
  -F "text=刚在 Rust 项目中完成了生命周期检查优化，体验非常丝滑！" \
  -F "images=@/Users/jsmn/Pictures/screenshot.png"
```

**服务器收到请求后会自动：**
1. 自动生成当前时间戳文件名（如 `20260828143000.md`）。
2. 将上传的图片自动归纳保存到 `source/tweets/YYYY/MM/assets/` 目录。
3. 写入 Markdown 内容并即时触发本地浏览器热重载。

#### 本地的 tweet 发布框

如果 rustpress 是在本地运行，首页上会有一个发布框：

![](assets/ScreenShot_2026-08-30_204105_162.png)

本地运行有后台接口，可以先生成文件再向 github 提交，完成内容的生产发布。

## 五、闲言分页聚合首页（`/t/`）

在 `config.toml` 中配置 `[taxonomies] tweets = "/t"` 后，访问 `https://yishulun.com/t/`（或本地 `http://localhost:1111/t/`）即可进入专属的微动态流聚合页：

1. **编译后的 Markdown 正文呈现**：自动将每条短动态由 Markdown 编译解析为安全纯净的 HTML 标签并保留代码高亮、链接与行内样式；
2. **多媒体与图片排版**：支持多图自适应网格与 Lightbox 灯箱大图预览；
3. **倒分页与无限流加载（Infinite Scroll）**：
   - 规则与站点首页完全一致：采用 **倒分页算法**，最新的一批动态永久固定在 `/t/index.html`，历史归档页依次生成为 `/t/index1.html`、`/t/index2.html`...；
   - 浏览时支持触底自动无感异步流式加载下一页；
4. **开发/测试域名下即时发布**：在 `dev_domains`（如 `localhost`、`127.0.0.1`、`dev.yishulun.com`）下访问 `/t/` 时，页面顶部同样会常驻「闲言碎语」多媒体发布框，支持随写随发、即时热重载！
