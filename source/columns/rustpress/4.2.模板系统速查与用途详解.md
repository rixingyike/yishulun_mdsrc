# 模板系统速查与用途详解

RustPress 的主题模板全部基于 **Tera** 模板引擎构建。为了让创作者在自定义或二次开发主题时胸有成竹，本篇将逐一详细拆解 `templates/` 目录下每一个模板文件与组件的功能职责、上下文输入以及修改定制方法。

---

## 一、全站页面模板功能速查清单

| 模板文件名 | 渲染页面类型 | 核心功能与职责 | 对应内容模型 / 触发路径 |
| :--- | :--- | :--- | :--- |
| **`base.html`** | 全站骨架母版 | 包含 `<html>`、`<head>`（SEO、CSS/JS 载入、统计广告代码）、顶部导航栏、主体内容槽 `{% block content %}` 及全局页脚。 | 全站所有页面继承基础 |
| **`home.html`** | 复合定制型首页 | 渲染顶部 Hero 问候大图、最新文章列表、短动态卡片及侧边栏。 | 首页 `/`（`config.toml` 中 `show_hero = true`） |
| **`index.html`** | 标准博文列表页 | 经典流式博文列表，包含文章卡片、发布时间、分类标签及倒分页翻页条。 | 首页 `/` 或历史分页 `/index2.html` |
| **`tweets.html`** | 闲言碎语聚合页 | 呈现微动态时间流、多图九宫格网格、互动按钮组及测试环境发表框。 | 闲言主页 `/t/` |
| **`post.html`** | 单篇博文详情页 | 渲染博文完整 Markdown 内容、文章元信息、文末作者名片、打赏码、前后篇导航及评论点赞系统。 | `source/YYYY/*.md`（`layout: blog/post`） |
| **`columns.html`** | 专栏总览与专栏主页 | 渲染全站专栏卡片总览，以及单个专栏的封面图、作者寄语与文章目录网格。 | `source/columns/` 与 `source/columns/<id>/README.md` |
| **`doc-item.html`** | 专栏章节沉浸阅读页 | 专业阅读版式，提供左侧响应式章节目录树（当前章节高亮）、顶部面包屑导航及前后篇翻页。 | 专栏子文章（`layout: doc-item`） |
| **`doc.html` / `docs.html`** | 结构化长文档页 | 树形层级技术文档展示。 | 独立结构化文档系统 |
| **`archives.html`** | 全量时间轴归档页 | 按年份倒序展示全站历史所有文章的时间轴清单。 | 历史归档 `/a/` |
| **`year_archive.html`** | 年份/月份归档页 | 按单一具体年份（如 2026 年）或月份聚合展示文章列表与年度统计计数。 | `/2026/` 或 `/2025/` |
| **`tags.html`** | 标签云总览页 | 汇总全站所有标签，以彩色胶囊标签云呈现，标明各标签下文章总数。 | 标签总览 `/tag/` |
| **`tag.html`** | 单标签文章列表页 | 展现带有指定标签（如 `Rust`）的所有文章分页列表。 | 单标签 `/tag/<tag_name>/` |
| **`categories.html`** | 分类体系总览页 | 展现全站多级分类层级树与文章统计。 | 分类总览 `/cat/` |
| **`category.html`** | 单分类文章列表页 | 展现指定分类（如 `后端`）下的所有文章分页列表。 | 单分类 `/cat/<category_name>/` |
| **`friends.html`** | 友情链接总览页 | 呈现友链申请规范说明与精美友链卡片网格。 | 友链主页 `/f/` |
| **`friend.html`** | 单个友链详情页 | 单独展示某位友人的专属页面。 | 单友链详情 |
| **`projects.html`** | 个人项目总览页 | 软件/开源作品展厅，展示项目 Logo、名称、版本号与简介。 | 项目主页 `/p/` |
| **`project.html`** | 项目独立发布页 | 软件官方主页，提供版本徽章、多平台安装/下载按钮组及特性介绍。 | `source/projects/<name>/` |
| **`works.html`** | 出版著作总览页 | 个人图书/著作书架网格展示。 | 著作主页 `/w/` |
| **`work.html`** | 著作单品详情页 | 单部图书详情，展现立体书封、出版社、年份、购买链接与大纲。 | `source/works/*.md` |
| **`about.html`** | 作者个人简介页 | 个人数字名片，展现履历、技术栈技能树、在线课程与联系方式。 | `source/about.md` |
| **`search.html`** | 客户端全文搜索页 | 基于 Lunr.js 驱动的毫秒级离线搜索结果呈现与关键词高亮页。 | 全文检索 `/search.html` |
| **`404.html`** | 404 错误页面 | 友好的找不到页面提示，提供返回首页与推荐文章入口。 | 错误页面 `/404.html` |

## 二、局部可复用组件（`templates/components/`）

为了实现代码复用和模块化维护，常见界面小部件被拆分在 `components/` 目录下：

```text
templates/components/
├── hero.html          # 首页大图问候横幅组件
├── sidebar.html       # 侧边栏（包含博主名片、全站最新文章、热门标签云、分类）
├── author-bio.html    # 正文底部作者名片与赞赏码弹窗
├── toc.html           # 文章目录大纲（Table of Contents）悬浮导航
└── three-buttons.html # 底部快捷操作按钮组（点赞、分享、回到顶部）
```

在任何模板中，您都可以通过以下单行语法轻松引入组件：

```html
{% include "components/sidebar.html" %}
```

## 三、常见自定义修改实战指南

### 1. 自定义修改全站页脚（Footer）
编辑 `themes/<theme>/templates/base.html` 底部的 `<footer>` 区域：
- 可以添加网站运行天数计算器、自定义 ICP 备案图标、公安联网备案号或个人版权声明。

### 2. 为文章详情页（`post.html`）添加文末版权声明
在 `post.html` 的 `{{ page.content | safe }}` 正文输出后加入：
```html
<div class="my-6 p-4 bg-gray-50 border-l-4 border-emerald-500 rounded text-sm text-gray-600">
    <p><strong>本文作者：</strong>{{ site.author.name }}</p>
    <p><strong>本文链接：</strong>{{ site.domain }}{{ page.url }}</p>
    <p><strong>版权声明：</strong>本博客所有文章除特别声明外，均采用 <a href="https://creativecommons.org/licenses/by-nc-sa/4.0/" class="underline" target="_blank">CC BY-NC-SA 4.0</a> 许可协议。转载请注明出处！</p>
</div>
```

### 3. 调整专栏阅读页（`doc-item.html`）左侧目录树宽度
在 `doc-item.html` 中找到侧边栏容器的 Tailwind 类名（如 `w-64` 或 `w-72`），修改为您期望的宽度（例如 `w-80`），即刻完成响应式调整。
