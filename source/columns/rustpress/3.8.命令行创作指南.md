# 命令行创作指南

静态博客的写作体验很大程度上取决于日常操作的便捷度。手动创建目录、编写 YAML 前言（Frontmatter）、维护专栏目录树以及制作封面往往费时费力。

RustPress 提供了强大且现代化的 **命令行子指令集（CLI）与原生辅助脚本**，涵盖从**日常博文**、**专栏连载**、**闲言微动态**到**专栏目录索引维护与高清封面生成**的全流程。

---

## 一、配置 PATH 环境变量（全局可用）

无论是通过包管理器安装，还是从源码本地编译，只需将 `rustpress` 可执行文件所在路径加入系统 `PATH` 环境变量，即可在任意终端窗口直接使用 `rustpress` 指令。

### 1. 源码编译与安装到 Cargo Bin
如果您是从源码编译使用 RustPress：

```bash
# 在 rustpress 源码仓库根目录下执行
cargo install --path .
```
Cargo 会自动将编译好的 release 二进制包安装到 `~/.cargo/bin/rustpress`。

### 2. 将 Cargo 路径加入 PATH 环境变量
确保您的 Shell 配置文件（如 `~/.bashrc`、`~/.zshrc` 或 `~/.config/fish/config.fish`）中已包含 `~/.cargo/bin`：

```bash
# 适用于 bash / zsh
export PATH="$HOME/.cargo/bin:$PATH"
```

保存后执行 `source ~/.bashrc`（或 `source ~/.zshrc`）使其生效。

### 3. 验证安装
在终端运行：

```bash
rustpress --help
```
若能输出子命令帮助列表，说明环境配置成功！

## 二、执行前置条件：必须在博客项目根目录

> [!IMPORTANT]
> **安全防护机制**：  
> 为了防止在错误的工作路径下生成杂乱文件，RustPress 的所有内容创建与运维指令（`new-blog`、`new-article`、`new-tweet`、`make-catalog`、`make-cover`）均具备**严格的前置环境检查**。  
> **当前执行目录下必须存在 `source` 目录**。如果未检测到 `source`，程序会友好拦截并提示：  
> `❌ 错误: 当前目录下未找到 source 目录，请在博客项目根目录下运行此命令！`

## 三、常用创作与运维指令详解

### 1. 创建日常博客文章 (`new-blog`)
自动识别当前年份、扫描并递增当前年份的最大数字文件名，自动生成标准 Frontmatter。

```bash
# 指令方式
rustpress new-blog "深入浅出 Rust 异步并发模型"

# 脚本方式
./new-blog.sh "深入浅出 Rust 异步并发模型"
```

**执行效果**：
- 自动在 `source/2026/`（当年年份）下创建 `16.md`。
- 自动写入包含 `title`、`date`、`layout: blog` 及正文一级标题的标准骨架。

---

### 2. 创建专栏文章并自动同步索引 (`new-article`)
在指定专栏目录下创建子文章，并**自动将其追加到该专栏 `README.md` 的 `catalog` 目录索引中**，无需手动修改目录树！

```bash
# 语法: rustpress new-article <专栏编号或目录名> [文章标题]
# 指令方式
rustpress new-article rustpress "3.8.命令行创作与运维指令(CLI)全指南"

# 脚本方式
./new-article.sh rustpress "3.8.命令行创作与运维指令(CLI)全指南"
```

**执行效果**：
1. 自动在 `source/columns/rustpress/` 下创建 `3.8.命令行创作与运维指令(CLI)全指南.md`。
2. 自动读取并更新 `source/columns/rustpress/README.md`，将该文章安全追加至 `catalog` 列表末尾。

---

### 3. 发布碎片化短动态闲言 (`new-tweet`)
极速记录灵感、技术摘录或生活随笔。

```bash
# 指令方式
rustpress new-tweet "今天完成了 RustPress CLI 指令扩展，写作与建站体验又上一层楼！"

# 脚本方式
./new-tweet.sh "今天完成了 RustPress CLI 指令扩展，写作与建站体验又上一层楼！"
```

**执行效果**：
- 自动按当下的「年份 / 月份」存放到 `source/tweets/YYYY/MM/` 目录中。
- 自动以毫秒级时间戳（如 `20260830193000.md`）命名，并写入 `layout: tweet` 元数据。

---

### 4. 专栏目录索引检查与重构 (`make-catalog`)
扫描专栏目录下的所有 Markdown 文件，进行自然排序（Natural Sort），自动检测并补全 `README.md` 中缺失的文章索引，同时**完好保留作者手动编排的顺序与分组分类标题**。

```bash
# 检查/更新指定专栏
rustpress make-catalog rustpress

# 一键检查/更新全站所有专栏
rustpress make-catalog --all

# 脚本方式
./make-catalog.sh rustpress
```

---

### 5. 专栏高清封面图片自动化生成 (`make-cover`)
基于专栏标题、作者及站点信息，自动生成典雅高雅的 900×500 标准专栏封面图片（`assets/cover.png`），并自动在 `README.md` 中绑定 `cover: "assets/cover.png"`。

```bash
# 为指定专栏生成默认浅色高雅封面
rustpress make-cover rustpress

# 为指定专栏生成故宫红风格封面
rustpress make-cover rustpress --style red

# 一键为全站所有专栏批量生成封面
rustpress make-cover --all

# 脚本方式
./make-cover.sh rustpress
```

## 四、CLI 核心指令速查总表

| 功能 | RustPress 指令 | 快捷 Shell 脚本 (Kebab-case) | 说明 |
| :--- | :--- | :--- | :--- |
| **新建日常博客** | `rustpress new-blog [标题]` | `./new-blog.sh [标题]` | 自动在 `source/YYYY/` 下自增编号创建 |
| **新建专栏文章** | `rustpress new-article <专栏> [标题]` | `./new-article.sh <专栏> [标题]` | 自动创建并**同步更新 `catalog` 列表** |
| **新建闲言动态** | `rustpress new-tweet [内容]` | `./new-tweet.sh [内容]` | 自动在 `source/tweets/YYYY/MM/` 创建时间戳动态 |
| **重构专栏目录** | `rustpress make-catalog [专栏/--all]` | `./make-catalog.sh [专栏]` | 自然排序比对并自动补齐 `catalog` |
| **生成专栏封面** | `rustpress make-cover [专栏/--all]` | `./make-cover.sh [专栏]` | 自动生成 900×500 高清封面并绑定 |
| **启动开发预览** | `rustpress serve` | `./start-dev.sh` | 启动带热重载的本地预览服务器 (`:1111`) |
| **停止开发预览** | - | `./stop-dev.sh` | 停止本地后台运行的开发服务器 |
| **查看服务状态** | - | `./status-dev.sh` | 查看开发服务器 PID 与 HTTP 响应状态 |
| **全站生产构建** | `rustpress build` | `./prod.sh` | 快速增量/全量生成 `public` 静态网站 |
