# 命令行创作指南

真正的极客最不能容忍的事情，就是写文章时还要伸手去抓鼠标——哪怕只是为了在深层文件夹里右键点一下「新建文本文档」。

最顺手的体验永远是：**双手不离开键盘，敲一行简短的命令，需要的文件、模板、目录索引全部自动创建好，直接进入编辑器开始码字**。不仅速度飞快，关键是姿势足够优雅。

RustPress 内置了一套精炼的 **命令行子指令集（CLI）与快捷脚本**，涵盖了日常博文、专栏连载、闲言微动态、专栏目录索引重构以及高清封面生成的全套创作操作。

---

## 一、配置 PATH 环境变量（全局可用）

把 `rustpress` 可执行文件加入系统的 `PATH` 环境变量，在任意终端目录下都能直接唤起：

### 1. 源码编译并安装到 Cargo Bin
如果你是从源码编译使用：

```bash
# 在 rustpress 源码仓库根目录下执行
cargo install --path .
```
Cargo 会自动将编译好的 release 二进制包放到 `~/.cargo/bin/rustpress`。

### 2. 检查环境变量
确保你的 Shell 配置文件（如 `~/.bashrc`、`~/.zshrc` 或 `~/.config/fish/config.fish`）包含了 `~/.cargo/bin`：

```bash
export PATH="$HOME/.cargo/bin:$PATH"
```

保存后执行 `source ~/.bashrc`（或 `source ~/.zshrc`）使其生效。

### 3. 验证指令
在终端运行：

```bash
rustpress --help
```
能看到子命令列表，说明配置就绪。

## 二、前置安全检查机制

> [!IMPORTANT]
> **安全防护提醒**：  
> 为了防止在错误的工作目录下误建文件，RustPress 的所有内容创建与运维指令（`new-blog`、`new-article`、`new-tweet`、`make-catalog`、`make-cover`）都有严格的前置校验。  
> **当前执行目录下必须存在 `source` 目录**。如果没检测到 `source`，程序会自动拦截并提示：  
> `❌ 错误: 当前目录下未找到 source 目录，请在博客项目根目录下运行此命令！`

## 三、常用创作指令详解

### 1. 新建日常博客文章 (`new-blog`)
自动识别当前年份、自增当前年份的最大数字文件名，自动生成标准 Frontmatter。

```bash
# 指令方式
rustpress new-blog "深入浅出 Rust 异步并发模型"

# 脚本方式
./new-blog.sh "深入浅出 Rust 异步并发模型"
```

**执行结果**：
- 自动在 `source/2026/`（当年年份）下创建 `16.md`；
- 自动写入包含 `title`、`date`、`layout: blog` 及正文一级标题的标准骨架。

---

### 2. 新建专栏文章并自动追加目录 (`new-article`)
在指定专栏目录下创建子文章，并**自动将其追加到该专栏 `README.md` 的 `catalog` 目录索引中**：

```bash
# 语法: rustpress new-article <专栏目录名> [文章标题]
rustpress new-article rustpress "3.8.命令行创作指南"

# 脚本方式
./new-article.sh rustpress "3.8.命令行创作指南"
```

**执行结果**：
1. 自动在 `source/columns/rustpress/` 下创建 `3.8.命令行创作指南.md`；
2. 自动读取并更新 `source/columns/rustpress/README.md`，将该文章追加至 `catalog` 列表末尾。

---

### 3. 发布碎片化短动态闲言 (`new-tweet`)
随手记录灵感或技术碎碎念：

```bash
# 指令方式
rustpress new-tweet "今天完成了 CLI 指令扩展，写作体验越来越轻快了！"

# 脚本方式
./new-tweet.sh "今天完成了 CLI 指令扩展，写作体验越来越轻快了！"
```

**执行结果**：
- 自动按当下的「年份 / 月份」存放到 `source/tweets/YYYY/MM/` 目录中；
- 自动以时间戳命名并写入 `layout: tweet` 元数据。

---

### 4. 专栏目录索引整理与重构 (`make-catalog`)
扫描专栏目录下的所有 Markdown 文件，进行自然排序（Natural Sort），自动补齐 `README.md` 中缺失的文章，同时**完好保留你手动排好的次序与分组分类标题**：

```bash
# 整理指定专栏
rustpress make-catalog rustpress

# 一键扫描整理全站所有专栏
rustpress make-catalog --all
```

---

### 5. 专栏高清封面图自动绘制 (`make-cover`)
基于专栏标题与作者名，自动绘制 900×500 标准专栏封面图片并绑定：

```bash
# 生成默认浅色高雅封面
rustpress make-cover rustpress

# 一键为全站所有专栏批量生成封面
rustpress make-cover --all
```

## 四、CLI 核心指令速查总表

| 功能 | RustPress 指令 | 快捷 Shell 脚本 | 说明 |
| :--- | :--- | :--- | :--- |
| **新建日常博客** | `rustpress new-blog [标题]` | `./new-blog.sh [标题]` | 自动在 `source/YYYY/` 下自增编号创建 |
| **新建专栏文章** | `rustpress new-article <专栏> [标题]` | `./new-article.sh <专栏> [标题]` | 自动创建并**同步更新 `catalog` 列表** |
| **新建闲言动态** | `rustpress new-tweet [内容]` | `./new-tweet.sh [内容]` | 自动在 `source/tweets/YYYY/MM/` 创建时间戳动态 |
| **重构专栏目录** | `rustpress make-catalog [专栏/--all]` | `./make-catalog.sh [专栏]` | 自然排序比对并自动补齐 `catalog` |
| **生成专栏封面** | `rustpress make-cover [专栏/--all]` | `./make-cover.sh [专栏]` | 自动生成 900×500 高清封面并绑定 |
| **启动开发预览** | `rustpress serve` | `./start-dev.sh` | 启动带热重载的本地预览服务器 (`:1111`) |
| **停止开发预览** | - | `./stop-dev.sh` | 停止本地后台运行的开发服务器 |
| **查看服务状态** | - | `./status-dev.sh` | 查看开发服务器 PID 与运行状态 |
| **全站生产构建** | `rustpress build` | `./prod.sh` | 增量/全量生成 `public` 静态产物 |

> **辩证分工：CLI 命令自动化 vs 编辑器精雕细琢**  
> 命令行指令在生成模板、自动递增编号、同步目录树与绘制封面时拥有极高的效率（正）；但试图用命令行替代长文精细排版和富媒体视觉校对则会显得死板低效（反）。  
> **边界原则**：将机械性的文件创建、元数据维护与目录整理完全交给 CLI；将创造性的正文撰写、代码剖析与阅读节奏留给专业编辑器（合）。分界在于「结构规范自动化，创造内容手搓化」。
