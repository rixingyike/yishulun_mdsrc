# 安装与本地开发预览

在没有静态博客前，想搭一个干净纯粹的技术博客，怎么总要先经历一轮折磨：配环境、装运行时、解决依赖冲突、盯着动辄几百兆的 `node_modules` 目录发呆——还没敲几行正文，当天的写作热情已经在解决编译错误时消耗殆尽。

如果你的诉求只是「把本地的 Markdown 扔进去，敲一行命令，在浏览器里秒级预览」，那么一个独立的 Rust 二进制程序就能搞定所有事情。

本篇用最简单直接的方式，带你在 macOS、Linux 或 Windows 环境下装好 RustPress，并在本地启动带`热重载`的开发服务器。

---

## 一、环境准备

安装 RustPress 之前，系统里需要有 Rust 语言工具链。如果还没装过，直接运行官方脚本：

```bash
# macOS / Linux 安装命令
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证安装
rustc --version
cargo --version
```

终端能打印出版本号，就说明环境准备好了。

---

## 二、安装 RustPress 的两种方式

### 方式 1：通过 Cargo 一键安装（推荐）

这是最省心的方式。Cargo 会从 [Crates.io](https://crates.io/crates/rustpress) 下载最新的稳定的二进制程序文件：

```bash
# 安装最新稳定版
cargo install rustpress --locked
```

> **参数说明**：`--locked` 强制使用经过验证的依赖锁定版本，防止上游依赖库突然更新导致编译翻车。

安装完成后，可执行文件会自动放到 `~/.cargo/bin`目录下。验证一下：

```bash
rustpress -V
```

能看到版本号输出，就说明安装成功了。

---

### 方式 2：从 GitHub 源码编译安装（开发者模式）

如果你想追最新的开发分支，或者打算动手给 RustPress 提 PR、改核心代码，那就从源码开始折腾：

```bash
# 1. 把源码拉到本地
git clone https://github.com/rixingyike/rustpress.git
cd rustpress

# 2. 编译 Release 发布版（开启最高优化）
cargo build --release

# 3. 将二进制丢到 PATH 路径下
cp target/release/rustpress ~/.cargo/bin/

# 4. 确认版本
rustpress -V
```

> **辩证取舍：二进制包 vs 源码编译**  
> 一键安装二进制能最大化降低心智负担，但若脱离源码，在遇到特殊模板编译边界或底层定制需求时便会失去排障纵深。  
> **边界原则**：纯写作与日常建站优先选用 Cargo 锁定版；涉及内核功能扩展或定制补丁时切换至源码工作流。两者的分界在于「当前诉求是内容生产还是引擎演进」。

---

## 三、项目初始化与目录规范

装好命令后，有两种方式开启你的博客站点：

### 1. 全新项目从零建站（`rustpress new`）

如果你打算从一张白纸开始：

```bash
# 创建名为 my-blog 的新博客
rustpress new my-blog

cd my-blog
```

### 2. 在已有 Markdown 仓库中直接就地初始化（`rustpress init`）

如果你手头已经有一堆记好的 Markdown 笔记，或者正打算从 Hexo、Hugo、VitePress 迁移过来：

```bash
cd /path/to/my-notes
rustpress init
```

`rustpress init` 具有「无损增强」特性：它只负责补齐 `config.toml`、`themes/` 模板以及必要的基础资源，**绝对不会碰你现有的任何 Markdown 文件**。

---

## 四、标准项目目录结构

初始化完成后，项目目录长成这样：

```text
my-blog/
├── config.toml           # 全局核心配置文件（站点名、作者、社交链接等）
├── source/               # Markdown 内容源目录（所有的写作都在这里）
│   ├── 2026/             # 按年份归档的日常博文
│   │   ├── 01.md
│   │   └── assets/       # 文章配图（Markdown 相对路径直接引用）
│   ├── columns/          # 体系化专栏与连载教程目录
│   │   └── rustpress/    # 具体专栏
│   │       ├── README.md # 专栏总览与目录配置
│   │       └── ...
│   ├── tweets/           # 短动态与闲言碎语（按年月分层）
│   ├── friends/          # 友情链接
│   ├── works/            # 著作与出版书籍
│   ├── projects/         # 开源项目与作品集
│   ├── about.md          # 作者个人简介
│   ├── CNAME             # 独立域名配置
│   └── ads.txt           # 谷歌广告认证文件
├── themes/               # 主题模板目录
│   ├── default/          # 经典科技感主题
│   └── light/            # 极简浅色主题
└── public/               # 编译出的纯静态产物（部署目标目录）
```

## 五、启动本地预览与热重载

RustPress 内置了轻量级本地服务器，支持 **Live Reload（保存自动刷新）**：

### 1. 运行 serve 命令

在项目根目录下敲命令：

```bash
# 启动本地开发服务（默认端口 1111）
rustpress serve

# 或者显式指定源目录、端口与输出目录
rustpress -m source serve --port 1111 --output-dir public
```

服务启动后，打开浏览器访问：  
👉 **`http://localhost:1111`**

只要你在 `source/` 里修改或新建 Markdown 文件并保存，浏览器就会在毫秒内自动刷新，省去反复按 `F5` 的机械动作。

### 2. 使用快捷脚本（方便后台驻留与自动端口清理）

如果你习惯把服务挂在后台：

```bash
# 启动开发服务器
./start-dev.sh

# 查看当前运行状态
./status-dev.sh

# 停止开发服务器
./stop-dev.sh
```

## 六、成功跑通的判定标准

满足以下 4 点，说明本地开发环境已经完全搭建就绪：

1. 终端运行 `rustpress -V` 正常打印版本号；
2. 运行 `rustpress serve` 没有任何报错；
3. 打开 `http://localhost:1111` 能顺畅浏览首页、专栏和文章；
4. 随意修改一篇 Markdown 文件的标题，浏览器自动刷出最新改动。
