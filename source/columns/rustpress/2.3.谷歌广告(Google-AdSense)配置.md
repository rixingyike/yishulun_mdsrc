# 谷歌广告 (Google AdSense) 配置

通过独立博客分享技术知识与创见的同时，接入 **Google AdSense（谷歌广告联盟）** 能够为您带来持续的被动收益，覆盖服务器、域名与 CDN 的日常开销。目前貌似只有域名开销，CDN 是免费的，服务器不存在，因为是纯静态，通过 Github Pages + Cloudflare 实现托管的。

本篇将完整介绍在 RustPress 静态站点中接入 Google AdSense 的标准流程，包括 **`ads.txt` 身份认证** 与 **广告代码模板嵌入**。

---

## 一、获取 AdSense 发布商 ID (Publisher ID)

1. 登录 [Google AdSense 控制台](https://www.google.com/adsense/) 并提交您的独立域名申请。
2. 在 **账号（Account） -> 设置 -> 账号信息** 中，复制您的 **发布商 ID（Publisher ID）**，格式通常为：
   `pub-1234567890123456`

---

## 二、配置 `ads.txt` 根目录防盗验证文件

Google 要求所有广告发布网站必须在根目录下提供 `ads.txt` 文件，以防止欺诈和未授权广告库存售卖。

### 1. 创建 `source/ads.txt`
在博客的 `source/` 根目录下创建 `ads.txt` 文件，例如：

```text
google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0
```

> **注意**：将上述 `pub-1234567890123456` 替换为您自己的真实发布商 ID。最后的 `f08c47fec0942fa0` 为 Google 官方固定的权威认证标记。

### 2. 保证构建时同步复制
在您的部署脚本或 `.github/workflows/deploy.yml` CI/CD 步骤中，确保构建后将该文件复制至 `public/` 产物根目录：

```bash
cp source/ads.txt public/ads.txt
```

部署完成后，在浏览器中直接打开 `https://yourdomain.com/ads.txt`，确保能直接查看该文本内容。

---

## 三、在主题模板中注入广告代码

Google AdSense 提供两种展示形式：**全自动广告（Auto Ads）** 与 **自适应广告单元（Ad Units）**。

### 1. 接入全局自动广告（Auto Ads）

编辑当前激活主题的骨架模板 `themes/light/templates/base.html` 或 `themes/default/templates/base.html`，在 `<head>` 区域加入 AdSense 官方载入脚本：

```html
<!-- Google AdSense Auto Ads -->
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-1234567890123456"
     crossorigin="anonymous"></script>
```

> **说明**：开启自动广告后，Google 的机器学习算法会自动分析您的博客页面排版，智能选择对阅读体验干扰最小的最佳位置（如文章段落间、侧边栏底部）展示响应式广告。

### 2. 接入固定广告单元（例如在文章正文底部或侧边栏）

如果您希望精确控制广告展现位置，可以在 AdSense 控制台创建「展示广告单元」，并将其代码放置在 `post.html` 或 `components/sidebar.html` 中：

```html
<div class="my-6 text-center">
    <ins class="adsbygoogle"
         style="display:block"
         data-ad-client="ca-pub-1234567890123456"
         data-ad-slot="9876543210"
         data-ad-format="auto"
         data-full-width-responsive="true"></ins>
    <script>
         (adsbygoogle = window.adsbygoogle || []).push({});
    </script>
</div>
```

## 四、Google 审核与排查要点

1. **内容丰富度**：申请审核前，建议博客拥有至少 15~20 篇高质量原创 Markdown 技术文章。
2. **页面完整性**：确保具有标准的“关于我”（`about.html`）、隐私政策或联系邮箱。
3. **ads.txt 爬取状态**：部署上线后 24~48 小时，进入 AdSense 控制台的「网站 -> 概览」页面，检查 `ads.txt` 状态是否已显示为绿色的「已获授权」。

有读者反馈现在申请 Google AdSense 账号审核，总是遇到「未通过」的情况，查看谷歌发来的拒绝邮件，理由无非就是不符合官方要求云云。不要相信邮件中所说的，谷歌拒绝通过，原因永远只有一个，就是咱的网站没有自然流量或自然流量极低！解决方法很简单，博客上线后，耐心写几篇甚至几十篇原创文章，主动发给朋友，请他们帮你点开 Look Look，时间久了，自然而然就能通过审核了。祝你好运。
