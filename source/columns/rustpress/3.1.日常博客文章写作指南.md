# 日常博客文章写作指南

在 RustPress 中，撰写日常技术博客与随笔体验极为流畅。所有内容完全基于纯 Markdown，配合精准的前言元数据（Frontmatter），系统会自动处理分类归档、标签索引、代码高亮以及独创的倒分页生成。

---

## 一、文章存放目录与资源组织

RustPress 推荐按年份分层存放日常博客文章：

```text
source/
├── 2026/                     # 年份目录
│   ├── 1.md                  # 序号或自定义名称文章
│   ├── 2.md
│   ├── why-rust-in-2026.md
│   └── assets/               # 本年份专属插图目录
│       └── memory-safety.png # Markdown 内引用: ![说明](assets/memory-safety.png)
└── 2025/
    ├── 1.md
    └── ...
```

所有的博客文章、专栏文章，图片默认都放在 md 文件同目录下的 assets 目录下。

---

## 二、Frontmatter 元数据规范

每篇 Markdown 顶部必须使用 `---` 包裹的 YAML 元数据块。以下是标准示例及字段说明：

```yaml
---
title: "深入浅出 Rust 异步运行时与 Tokio 核心原理"
date: "2026-08-28 14:30:00"
layout: blog
tags: ["Rust", "异步编程", "Tokio", "后端架构"]
categories: ["技术", "后端"]
draft: false
description: "深度剖析 Future 状态机、Task 调度、Waker 唤醒机制与 Reactor 事件循环。"
cover: "assets/tokio-banner.png"
comments: true
---

# 深入浅出 Rust 异步运行时与 Tokio 核心原理

正文从这里开始编写……
```

blog 是博客文章的模板名称，每类内容都有一个布局模板。

### 核心字段速查表

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `title` | `String` | 是 | 文章主标题。若缺失会自动提取正文第一个 `# 一级标题`。 |
| `date` | `String` | 推荐 | 发布时间（格式：`YYYY-MM-DD HH:MM:SS`），用于时间轴排序与归档。 |
| `layout` | `String` | 否 | 布局模板，默认为 `blog` 或 `post`。 |
| `tags` | `Array` | 否 | 标签数组，例如 `["Rust", "Web"]`，自动汇入 `/tag/` 页面。 |
| `categories` | `Array` | 否 | 分类数组，例如 `["技术", "后端"]`，自动汇入 `/cat/` 页面。 |
| `draft` | `Bool` | 否 | 草稿开关。`true` 时本地预览可见，生产构建自动过滤。 |
| `description` | `String` | 否 | 文章摘要，用于社交分享卡片与首页文章列表简介。 |
| `cover` | `String` | 否 | 文章封面图相对或绝对路径。 |
| `comments` | `Bool` | 否 | 是否为此文章开启底部的 Giscus 评论区。 |

## 三、草稿隔离机制（Draft Mode）

- **本地写作时**：设置 `draft: true`。在执行 `rustpress serve`（或访问 `http://localhost:1111`）时，该文章正常渲染，并在标题旁展示黄色 <kbd style="background:#fef3c7;color:#92400e;border:1px solid #fcd34d;padding:2px 6px;border-radius:4px;font-size:12px;">草稿</kbd> 标识，方便校对排版。
- **生产发布时**：执行 `rustpress build` 时，系统自动排除所有草稿文章，不生成 HTML，不进入 RSS、Sitemap 与搜索索引，彻底杜绝半成品外泄。

---

## 四、RustPress 倒分页机制优势

传统博客在发布新文章时，历史所有分页的 URL 内容会发生顺移，导致搜索引擎缓存失效和爬虫重复抓取。

**RustPress 倒分页算法**：
1. 首页永远展示最新发布的 8 篇文章。
2. 历史早期文章固定封存在最早的分页编号中。
3. **历史分页内容与 URL 永久固化不变**，对 CDN 缓存与搜索引擎收录极其友好。

倒分页不仅针对首页数据，对其他分页列表数据（例如分类、标签）也是如此，均是按照时间倒序序列，永远只生成最新一个页面的数据。

## 五、一键新建博客文章（CLI 指令与辅助脚本）

RustPress 提供了内置 CLI 命令与辅助脚本，免去手动建立文件和填写 Frontmatter 模版的繁琐步骤：

```bash
# 推荐方式：使用 RustPress CLI 子命令
rustpress new-blog "Rust 并发编程最佳实践"

# 脚本方式
./new-blog.sh "Rust 并发编程最佳实践"
```

**自动化处理机制**：
1. 自动定位当前年份（如 `source/2026/`）。
2. 自动检索当前年份下的最大数字编号并递增（如自动命名为 `3.md`）。
3. 自动生成标准 YAML 前言元数据（含实时时间戳）与正文骨架。直接打开文件即可专注写作！

注意，使用 rustpress 指令时，要确保当前目录下有一个 source 目录，否则会报错。
