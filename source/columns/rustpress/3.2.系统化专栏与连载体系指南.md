# 系统化专栏与连载体系指南

零散的技术博文适合记录碎片化的排障碎碎念，但当你打算系统性输出一门技术、撰写实战连载课程或开源电子书时，普通的博客列表就显得力不从心了：

- 读者点进主页像在逛超市特价区，完全不知道从哪一篇开始读起；
- 缺少左侧多级目录树和章节高亮；
- 翻到文末没有上一篇/下一篇的连贯导航。

**RustPress 专门设计了「专栏系统（Columns）」**。只需要一个专栏目录加一份 `README.md`，就能自动生成媲美专业电子书阅读平台的沉浸式体验。

本篇系统介绍专栏的目录组织、章节编排与全套自动化工具。

---

## 一、专栏目录与文件组织

所有专栏统一存放在 `source/columns/<专栏目录名>/` 下：

```text
source/columns/
├── rustpress/                  # 专栏目录（如 rustpress）
│   ├── README.md               # 专栏总控台与目录结构定义（必须）
│   ├── assets/
│   │   └── cover.png           # 专栏封面图（标准尺寸 900x500 或 800x450）
│   ├── 1.1.安装与本地开发预览.md # 章节文章
│   ├── 1.2.GitHub-CI-CD部署.md
│   └── ...
└── harness/                    # 另一个专栏
    ├── README.md
    └── ...
```

---

## 二、专栏总控制台：`README.md`

专栏根目录下的 `README.md` 是该专栏的入口元数据文件：

```yaml
---
title: "RustPress 配置与使用指南"
cover: "assets/cover.png"
layout: columns
description: "从零安装、核心配置、全内容模型使用到主题深度定制，全面掌握 RustPress 现代静态博客。"
product_id: "yishulun.com_columns_rustpress"
price: 0.0
draft: false
tags: ['RustPress', '静态博客', 'Rust', '主题开发']
catalog:
  - "一、安装与快速上手"
  - "1.1.安装与本地开发预览.md"
  - "1.2.GitHub-CI-CD自动化部署.md"
  - "二、核心配置详解"
  - "2.1.全局基础配置与config.toml详解.md"
  - "2.2.谷歌统计(Google-Analytics)配置.md"
createTime: "2026-08-28 10:00:00"
---

# RustPress 配置与使用指南

这里写专栏的导语、课程大纲或作者寄语。正文内容会作为专栏聚合主页的介绍呈现。
```

### 关键属性解析
1. **`layout: columns`**：指示模板以专栏聚合主页渲染，展示封面大图、作者介绍与章节目录卡片；
2. **`catalog`**：**专栏篇章的绝对呈现次序**。RustPress 严格按照 `catalog` 中的文件名列表进行章节排版并计算前后篇链接。支持像「一、安装与快速上手」这样的分类分组标题；
3. **`draft`**：专栏全局草稿开关。设为 `true` 时整个专栏在生产环境自动隐藏。

---

## 三、专栏子文章排版规范（`layout: doc-item`）

专栏下属的每篇 Markdown 文章头部必须指定 `layout: doc-item`：

```yaml
---
title: "安装与本地开发预览"
date: "2026-08-28 10:10:00"
layout: doc-item
tags: ["RustPress", "安装指南"]
---

# 安装与本地开发预览

正文从这里开始……
```

在阅读专栏文章时，页面会自动装配全套专业阅读组件：
- **左侧响应式目录树**：多级折叠展开，自动高亮当前阅读小节；
- **顶部面包屑导航**：`首页 / 专栏 / 专栏名称 / 当前文章`；
- **底部上一篇 / 下一篇翻页**：无需退回列表页，读者能一口气连续读完整本书；
- **右侧大纲悬浮导航 (TOC)**：根据正文中的 `##`、`###` 标题自动提取大纲。

> **辩证演进：点状博文 vs 线性专栏**  
> 专栏系统能提供极高的上下文连贯性与专业结构沉淀；但若一开始就大动干戈规划十几章的大部头，极易因某一节卡壳导致全盘烂尾。  
> **边界原则**：先通过独立的日常博文对各个技术难点进行点状试错与单篇验证；待逻辑链路成熟后，再将其汇编重组为线性专栏。分界在于「知识处于探索发散阶段还是沉淀收敛阶段」。

## 四、专栏自动化利器（一键建文、理目录、生封面）

长篇连载最烦手动维护目录和画图，RustPress 提供了三组自动化指令：

### 1. 一键新建专栏文章并自动追加到目录 (`new-article`)
```bash
# 指令方式
rustpress new-article rustpress "深入理解增量编译机制"

# 脚本方式
./new-article.sh rustpress "深入理解增量编译机制"
```
**功能**：在专栏目录下创建带标准元数据的 Markdown 文件，并**自动把文件名追加到 `README.md` 的 `catalog` 列表末尾**，不用手动去改目录树。

---

### 2. 目录自动扫描与理顺 (`make-catalog`)
```bash
# 理顺指定专栏
rustpress make-catalog rustpress

# 批量扫描理顺全站所有专栏
rustpress make-catalog --all
```
**功能**：智能扫描专栏下的 Markdown 文件，采用自然排序（Natural Sort）自动补全 `catalog` 中遗漏的新文章，同时**完好保留你手动调整好的章节顺序与分类标题**。

---

### 3. 专栏高清封面自动绘制 (`make-cover`)
```bash
# 为指定专栏生成默认浅色高雅封面
rustpress make-cover rustpress

# 批量为全站所有专栏生成封面图
rustpress make-cover --all
```
**功能**：提取专栏标题与作者名，根据内置高雅配色方案自动绘制 900×500 标准高清封面图，直接存入 `assets/cover.png` 并绑定到 `README.md`，把 Photoshop 扔到一边。
