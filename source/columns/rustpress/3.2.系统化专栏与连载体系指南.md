# 系统化专栏与连载体系指南

零散的技术博文适合记录点状经验，而当您要系统性输出一门技术、撰写深度实战教程或电子书时，RustPress 的 **专栏系统（Columns）** 能为您提供媲美专业在线阅读平台的沉浸式体验。

本篇将详细介绍专栏的组织规范、目录排序机制以及全套自动化辅助工具。

---

## 一、专栏目录与文件组织

所有专栏统一保存在 `source/columns/<column_name>/` 目录下：

```text
source/columns/
├── rustpess/                   # 专栏目录
│   ├── README.md               # 专栏总览与目录排版控制台（必须）
│   ├── assets/
│   │   └── cover.png           # 专栏封面图（标准尺寸 900x500 或 800x450）
│   ├── 1.1.安装与本地开发预览.md # 专栏子文章
│   ├── 1.2.GitHub-CI-CD部署.md
│   └── ...
└── harness/
    ├── README.md
    └── ...
```

---

## 二、专栏总控制台：`README.md`

专栏根目录下的 `README.md` 是专栏的入口元数据定义文件：

```yaml
---
title: "RustPress 配置与使用指南"
cover: "assets/cover.png"
layout: columns
description: "从零安装、核心配置、全内容模型使用到主题深度定制，全面掌握 RustPress 现代静态博客。"
product_id: "yishulun.com_columns_rustpress"
price: 0.0
draft: false
tags: ['RustPress', '静态博客', 'Rust', '主题开发']
catalog:
  - "一、安装"
  -  "1.1.安装与本地开发预览.md"
  -  "1.2.GitHub-CI-CD自动化部署.md"
  - "二、配置"
  -  "2.1.全局基础配置与config.toml详解.md"
  -  "2.2.谷歌统计(Google-Analytics)配置.md"
createTime: "2026-08-28 10:00:00"
---

# RustPress 配置与使用指南

这里写专栏的欢迎致辞、课程大纲简介或作者寄语。正文内容将作为专栏主页顶部介绍呈现。
```

### 关键属性解析
1. **`layout: columns`**：指示模板以专栏聚合页进行渲染，展现专栏封面、介绍与篇章目录网格。
2. **`catalog`**：**专栏篇章的绝对呈现次序**。RustPress 会严格按照 `catalog` 列表里的文件名顺序进行章节排版与前后篇链接计算。列表还支持子分类，“安装”与“配置”就是子分类。
3. **`draft`**：专栏全局草稿开关。设为 `true` 时整个专栏在生产环境自动隐藏。

---

## 三、专栏子文章排版规范（`layout: doc-item`）

专栏下属的每篇 Markdown 文章头部应指定 `layout: doc-item`：

```yaml
---
title: "安装与本地开发预览"
date: "2026-08-28 10:10:00"
layout: doc-item
tags: ["RustPress", "安装指南"]
---

# 安装与本地开发预览
正文……
```

在阅读专栏文章时，系统会自动呈现：
- **左侧响应式目录树**：高亮当前小节，支持快速点击跳转与多级折叠。
- **面包屑导航**：`首页 / 专栏 / 专栏名称 / 当前文章`。
- **底部上一篇 / 下一篇翻页**：读者无需返回列表即可连续沉浸阅读。
- **右侧内容大纲**：右侧会自动根据 md 内容生成大纲。

## 四、专栏自动化利器全家桶（CLI 指令与脚本）

为了减轻手动维护长专栏目录和封面的负担，RustPress 提供了内置 CLI 命令与高效脚本：

### 1. 一键新建专栏文章（`new-article`）
```bash
# 推荐方式：使用 RustPress CLI 指令
rustpress new-article rustpress "深入理解增量编译机制"

# 脚本方式
./new-article.sh rustpress "深入理解增量编译机制"
```
**功能**：自动在专栏目录下创建带有标准 Frontmatter 的 Markdown 文件，并**自动将文件名追加到 `README.md` 的 `catalog` 列表中**！

---

### 2. 目录自动整理与同步（`make-catalog`）
```bash
# 为指定专栏自动同步目录列表
rustpress make-catalog rustpress
# 或使用脚本
./make-catalog.sh rustpress

# 批量扫描并同步全站所有专栏的目录
rustpress make-catalog --all
```
**功能**：智能扫描专栏下所有 Markdown 文件，保留您已经手动调整好的篇章顺序与分类小节标题，自动检测新增加的文件并根据创建时间或自然数序号追加到 `catalog` 中。

---

### 3. 专栏精美封面自动生成（`make-cover`）
```bash
# 为指定专栏一键生成封面图 assets/cover.png
rustpress make-cover rustpress
# 或使用脚本
./make-cover.sh rustpress

# 批量为全站所有专栏生成封面图
rustpress make-cover --all
```
**功能**：提取专栏标题与作者，根据内置优雅色板（清新绿、科技蓝、故宫红等）自动绘制标准高清封面图并保存至 `assets/cover.png`，免去打开 Photoshop 的麻烦！
