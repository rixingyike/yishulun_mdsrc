# 个人著作 (Works) 展示与管理

对于写过实体书、付费小册或录过精品课程的技术作者来说，常常面临一个展示困境：把书封和购买链接硬塞在博客侧边栏，页面挤得像小广告电线杆；单独写一篇推荐博文，不出两周就被时间流冲得无影无踪。

写书的过程堪称脱发之旅，如果不给它一个体面立体的专属展厅，实在对不起当年熬过的无数个通宵。

**RustPress 专门设计了「个人著作模型（Works）」**。以立体书架的形式集中陈列你的出版成果，支持展示立体书封、出版社信息、购买通道以及图书勘误大纲。

---

## 一、著作目录结构规范

所有著作存放在 `source/works/` 目录下：

```text
source/works/
├── README.md                 # 著作总览页（介绍出版历程）
├── assets/                   # 高清图书封面
│   ├── minigame.png
│   └── miniprogram-0-1.png
├── miniprogram-0-1.md        # 单部著作 1
└── minigame-dev.md           # 单部著作 2
```

---

## 二、单部著作 Markdown 规范

新建一个著作文件（例如 `source/works/miniprogram-0-1.md`）：

```yaml
---
title: "小程序从0到1"
subtitle: "微信全栈开发实战"
layout: work
cover: "assets/miniprogram-0-1.png"
publisher: "机械工业出版社"
year: 2017
url: "https://e.jd.com/30401467.html"
description: "从零学习微信小程序开发，系统覆盖双线程架构、网络通信与云开发一体化实战。"
createTime: 2025-11-05 08:00:00
comments: false
---
```

### 字段速查表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | `String` | 书籍/著作主标题。 |
| `subtitle` | `String` | 副标题或定位（如「微信全栈开发实战」）。 |
| `layout` | `String` | 固定指定为 `work`。 |
| `cover` | `String` | 图书立体封面图相对路径。 |

| `url` | `String` | 购买直链或在线试读链接。 |
| `description`| `String`| 一句话推荐语与内容简介。 |

## 三、前端双层展示效果

1. **著作汇总书架（`/w/`）**：以书架式卡片网格呈现，展示书本封面、出版社徽章、出版年份与购买直达按钮；
2. **书籍详情独立页（`/w/miniprogram-0-1.html`）**：左侧展示立体书封与元数据，右侧展示完整的书籍介绍、读者评价与勘误更新。

> **辩证隔离：商业成果展厅 vs 纯粹技术分享**  
> 专门的著作模型能为作者的实体书与付费课程提供立体的展示窗口，沉淀专业声望（正）；但若将购买导流粗暴混入日常技术博文中，会严重伤害读者的信任与阅读纯粹性（反）。  
> **边界原则**：将出版与商业导购完全收拢在 `/w/` 专属展厅中，日常博文保持零干扰的技术干货（合）。分界在于「商业沉淀在专区，技术纯粹留正文」。
