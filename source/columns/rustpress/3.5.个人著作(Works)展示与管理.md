# 个人著作 (Works) 展示与管理

对于写过实体书、付费小册子或录过精品课程的技术作者来说，常常面临一个展示困境：把书封和购买链接硬塞在博客侧边栏，页面挤得像小广告电线杆；单独写一篇推荐博文，不出两周就被时间流冲得无影无踪。

写书的过程堪称脱发之旅，如果不给它一个体面的专属展厅，实在对不起当年熬过的无数个通宵。

**RustPress 专门设计了「个人著作模型（Works）」**。以立体书架的形式集中陈列出版成果，支持展示立体书封、出版社信息、购买通道以及图书勘误大纲。

---

## 一、著作目录结构规范

所有著作存放在 `source/works/` 目录下：

```text
source/works/
├── README.md                 # 著作总览页（介绍出版历程）
├── assets/                   # 高清图书封面目录
│   ├── minigame.png
│   └── miniprogram-0-1.png
├── miniprogram-0-1.md        # 单部著作 1
└── minigame-dev.md           # 单部著作 2
```

---

## 二、单部著作 Markdown 规范

新建一个著作文件（例如 `source/works/miniprogram-0-1.md`）：

```yaml
---
title: "小程序从0到1"
subtitle: "微信全栈开发实战"
layout: work
cover: "assets/miniprogram-0-1.png"
publisher: "机械工业出版社"
year: 2017
url: "https://e.jd.com/30401467.html"
description: "从零学习微信小程序开发，系统覆盖双线程架构、网络通信与云开发一体化实战。"
createTime: 2025-11-05 08:00:00
comments: false
---

# 小程序从0到1：微信全栈开发实战

已出版实体技术著作《小程序从0到1》的官方介绍页面。

### 📖 本书核心内容
- **基础篇**：深入剖析小程序底层双线程架构、MINA 框架与 Flex 布局；
- **进阶篇**：精讲组件封装、自定义事件总线、状态管理与多端适配；
- **实战篇**：通过完整的商城与社区案例，带领读者走通全栈开发全流程。

### 🛒 购买渠道
- 京东自营：[立即购买](https://e.jd.com/30401467.html)
- 当当自营：各大电商平台均有销售
```

### 字段速查清单

- **`title`**（`String` · 必填）
  - 书籍/著作主标题。
- **`subtitle`**（`String` · 可选）
  - 副标题或定位（如「微信全栈开发实战」）。
- **`layout`**（`String` · 必填）
  - 固定指定为 `work`。
- **`cover`**（`String` · 可选）
  - 图书立体封面图相对路径。
- **`publisher`**（`String` · 可选）
  - 出版社或发行机构（例如「机械工业出版社」）。
- **`year`**（`Integer` · 可选）
  - 出版年份（如 `2017`），用于年份归档与排序。
- **`url`**（`String` · 可选）
  - 购买直链或在线试读链接。
- **`description`**（`String` · 可选）
  - 一句话推荐语与内容简介。

## 三、前端双层展示效果

1. **著作汇总书架（`/w/`）**：以书架式卡片网格呈现，展示书本封面、出版社徽章、出版年份与购买直达按钮；
2. **书籍详情独立页（`/w/miniprogram-0-1.html`）**：左侧展示立体书封与元数据，右侧展示完整的书籍介绍、读者评价与勘误更新。

专门的著作模型，为作者的实体书与付费课程，提供了立体的展示窗口。如果将购买链接粗暴地混入日常技术博文中，会严重伤害读者的信任与阅读纯粹性。所以，在 RustPress 中，将出版与商业导购完全收拢在 `/w/` 专属展厅中，日常博文则保持是零广告的技术干货。这样就解决了广告与技术沉淀矛盾对立的问题。在 RustPress 前期版本中设置有 ad 广告位，在最新版本中，已经不再这样做，同时也不鼓励定制开发者这样做。
