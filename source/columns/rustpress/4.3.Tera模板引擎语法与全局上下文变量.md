# Tera 模板引擎语法与全局上下文变量

RustPress 选用 **Tera** 作为唯一的模板渲染引擎。Tera 深度借鉴了 Python 社区的 Jinja2 和 Django 模板设计哲学，语法优雅直观，同时依托 Rust 编译器实现了极致的高性能与类型安全。

本篇将系统梳理 Tera 的核心语法、常用过滤器以及 RustPress 运行时自动注入的**全局上下文变量大全**。

---

## 一、Tera 核心语法与结构

### 1. 变量输出与安全渲染
```html
<!-- 输出普通变量（默认会自动进行 HTML 实体转义以防止 XSS） -->
<h1>{{ page.title }}</h1>

<!-- 输出编译后的 HTML 正文（必须加 | safe 过滤器，否则正文标签会被转义显示为源码） -->
<div class="prose">
    {{ page.content | safe }}
</div>
```

---

### 2. 条件判断（`if / elif / else`）
```html
{% if page.draft %}
    <span class="badge-draft">草稿</span>
{% elif page.is_pinned %}
    <span class="badge-pinned">置顶</span>
{% else %}
    <span class="badge-normal">普通</span>
{% endif %}
```

---

### 3. 循环遍历（`for ... in`）
```html
<ul>
{% for tag in page.tags %}
    <li><a href="/tag/{{ tag }}/"># {{ tag }}</a></li>
{% empty %}
    <li>暂无标签</li>
{% endfor %}
</ul>
```

在 `for` 循环内部，Tera 自动提供辅助状态变量：
- `loop.index`：从 1 开始的当前迭代索引。
- `loop.index0`：从 0 开始的当前迭代索引。
- `loop.first`：布尔值，是否为第一项。
- `loop.last`：布尔值，是否为最后一项。

---

### 4. 模板继承与块插槽（`extends` & `block`）
```html
<!-- 子模板 post.html -->
{% extends "base.html" %}

{% block title %}{{ page.title }} - {{ site.name }}{% endblock title %}

{% block content %}
<main class="container mx-auto px-4 py-8">
    <article>
        <h1>{{ page.title }}</h1>
        <div class="content">{{ page.content | safe }}</div>
    </article>
</main>
{% endblock content %}
```

## 二、常用内置过滤器（Filters）速查表

| 过滤器 | 语法示例 | 说明与效果 |
| :--- | :--- | :--- |
| `safe` | `{{ page.content \| safe }}` | 标记为安全 HTML，跳过自动转义直接渲染。 |
| `default` | `{{ site.author.maxim \| default(value="博学审问") }}` | 当变量不存在或为空时提供兜底默认值。 |
| `truncate` | `{{ post.description \| truncate(length=80) }}` | 截取前 80 个字符并在末尾自动附加省略号 `...`。 |
| `slice` | `{% for p in posts \| slice(end=5) %}` | 数组切片，仅提取前 5 篇文章。 |
| `length` | `{{ page.tags \| length }}` | 返回数组元素个数或字符串长度。 |
| `lower` / `upper` | `{{ post.slug \| lower }}` | 转换为小写或大写。 |
| `first` / `last` | `{{ page.tags \| first }}` | 获取数组的首个元素或最后一个元素。 |

## 三、RustPress 全局上下文变量（Context）大盘点

在渲染任何模板时，RustPress 会将以下完整的数据上下文注入给 Tera 引擎供您调用：

### 1. `site` 对象（全站全局配置）
- `site.name`：站点名称（如 `"艺述论"`）
- `site.description`：站点描述与 Slogan
- `site.domain`：正式线上绝对域名（如 `"https://yishulun.com"`）
- `site.base_url`：当前环境基准 URL
- `site.author.name`：作者昵称
- `site.author.bio`：作者一句话简介
- `site.author.maxim`：作者座右铭
- `site.author.avatar`：作者头像图片路径
- `site.author.email`：联系邮箱
- `site.author.donate_qrcode`：赞赏码图片路径
- `site.social`：包含 `github`, `twitter`, `youtube`, `zhihu`, `bilibili`, `rss` 等平台主页地址字典
- `site.icp_license`：ICP 备案号
- `site.start_year`：创站起始年份

### 2. `page` 对象（当前正在渲染的页面元数据）
- `page.title`：文章或专栏标题
- `page.content`：Markdown 转换后的 HTML 正文内容字符串
- `page.date_ymd`：发布日期（格式：`2026-08-28`）
- `page.create_time_hm`：发布时间（格式：`14:30`）
- `page.tags`：标签字符串列表数组
- `page.categories`：分类层级列表数组
- `page.draft`：布尔值，是否为草稿
- `page.url`：当前页面的相对访问路径（如 `"/2026/01.html"`）
- `page.description`：文章摘要与 Meta 描述
- `page.cover`：封面图片路径
- `page.comments`：布尔值，是否开启评论区

### 3. 数据集合对象
- `posts` / `all_posts`：文章对象列表数组。
- `columns`：全站专栏元数据数组。
- `features`：全局功能开关（`features.search`, `features.comments`, `features.analytics` 等）。
- `analytics.google_id`：GA4 衡量 ID。
- `comments`：评论组件配置字典。
