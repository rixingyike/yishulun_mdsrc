# RustPress 简介与核心特性

在这个动态内容与重量级后端泛滥的时代，个人网站与技术博客究竟需要怎样的基础设施？

对于追求极致性能、完全自主掌控与长久可维护性的创作者而言，**纯静态生成（Static Site Generation, SSG）** 无疑是最优雅的选择。而 **RustPress**（[GitHub 仓库](https://github.com/rixingyike/rustpress) | [Crates.io 类库](https://crates.io/crates/rustpress)），正是基于 Rust 语言深度打磨的一款超轻量、高性能、零后端依赖的现代静态博客程序。

### 1. 极致性能与原生安全（Rust 强力驱动）
RustPress 采用系统级编程语言 Rust 编写，编译为单一二进制可执行文件。没有 Node.js 的海量 `node_modules` 依赖黑洞，没有 Python 虚拟环境的版本冲突，启动迅速、内存占用极低。面对数百上千篇文章，构建仅需数百毫秒即可瞬间完成。

### 2. 毫秒级增量编译机制
在传统的静态博客中，修改一篇文章往往需要全量重新编译数千个页面。RustPress 内建了智能的增量编译（Incremental Build）机制：
- 通过 `build.toml` 精确记录每次编译的时间戳与元数据。
- 在增量模式下，仅重新解析和渲染发生变更或新增的 Markdown 文件，同时按需局部更新关联的索引、分类、归档与 RSS。
- 极大地降低了本地调试与持续集成（CI）服务器的构建负担。

### 3. 独创的“倒分页（Reverse Pagination）”算法
传统博客分页最常被忽略的严重痛点是：**每发布一篇新文章，历史所有分页的 URL 内容都会发生整体偏移**。
- 例如原本在 `page 2` 的第 10 篇文章被挤到了 `page 3`。
- 搜索引擎爬虫（Googlebot、Baiduspider）抓取到的历史分页缓存全部失效，外部链接也会错位。

**RustPress 创新性地实现了倒分页系统**：
- 首页 `index.html` 永远呈现最新的内容。
- 历史归档分页从创站的第一批文章开始固定编号（如 `index2.html`, `index3.html`, ...），一旦生成，**历史分页里的文章内容与顺序永久保持不变**。
- 这种机制对搜索引擎索引机制极为友好，彻底杜绝了爬虫的重复抓取与死链问题。

### 4. 丰富多元的内容模型（Content Models）
RustPress 不仅仅是一个单纯的文章列表系统，它原生支持了多种满足创作者深度表达的内容形态：
- 📝 **常规博客（Blog Posts）**：支持时间轴倒序、分类层级（Categories）、标签云（Tags）与年份/月份多级归档。
- 📚 **专栏与连载体系（Columns）**：专为系统化长文、系列教程设计的专栏页面，支持自定义目录（Catalog）树形层级排序与专属封面。
- 📖 **长篇文档（Docs）**：左侧树形目录导航、多级章节折叠、全屏阅读优化的技术文档系统。
- 💬 **碎片动态（Tweets / 闲言）**：类似个人去中心化微语录，支持通过本地 API 直接发布碎片化想法与快照，无需打开编辑器。
- 🏆 **著作（Works）、项目（Projects）与友链（Friends）**：内建专有 Layout，开箱即用。

### 5. 零后端依赖的本地搜索引擎与互动
- 内置 **Lunr.js** 离线全文搜索索引生成，构建时自动输出 `search.json`，搜索完全在客户端毫秒级完成，不需要配置外部 Elasticsearch 或 Algolia。
- 原生支持 **RSS / Atom 订阅**（`rss.xml`）与 **搜索引擎地图**（`sitemap.xml`）。
- 本地开发服务器集成 **WebSocket 实时热重载（Live Reload）**，保存 Markdown 即刻在浏览器无刷新刷新。
