# 短动态闲言 (Tweets) 与多媒体管理

在长篇博文与系统化专栏之外，创作者日常往往会有许多碎片化的灵感、阅读摘抄、技术随笔或生活快照。如果每条都要写成正式文章，心理门槛太高；如果只发在第三方社交平台，数据又无法长期沉淀在自己的独立网站上。

RustPress 创新性地在静态博客体系中内建了 **短动态系统（Tweets / 闲言）**，让您拥有完全自主掌控的个人去中心化微语录。

---

## 🐦 1. Tweets 短动态架构规范

短动态在 `source/tweets/` 目录下按“年份 / 月份”分层存放：

```text
source/tweets/
└── 2026/
    └── 08/
        ├── assets/                   # 动态关联的配图
        │   ├── 20260828143000_0.jpg
        │   └── 20260828143000_1.jpg
        └── 20260828143000.md         # 动态内容 Markdown
```

### 单条动态 Markdown 示例

```markdown
---
date: 2026-08-28 14:30:00
layout: tweet
images:
  - "/tweets/2026/08/assets/20260828143000_0.jpg"
  - "/tweets/2026/08/assets/20260828143000_1.jpg"
---

今天把 RustPress 的增量编译机制重构了一遍，毫秒级响应带来的流畅感真的让人欲罢不能。静态博客的终局，就应该是极简、极速与彻底的数据掌控。
```

---

## 🖼️ 2. 多图九宫格自适应排版

在主题模板中，RustPress 针对 `images` 列表提供了响应式网格布局：
- **单图**：自适应大图展示，保持原图优雅比例。
- **双图**：横向双列对齐。
- **三图/四图/九图**：智能网格缩略图排版，支持点击灯箱（Lightbox）查看高清原图。

---

## ⚡ 3. 本地即时发布 API（`/api/tweets`）

为了让发布动态像发朋友圈或 Twitter 一样简单，RustPress 的本地开发服务器内建了快捷发布端点：

- **接口地址**：`POST http://localhost:1111/api/tweets`
- **请求格式**：`multipart/form-data`
- **参数**：
  - `text`：动态文字内容
  - `images`：上传的图片文件（可多选）

### 请求示例（使用 curl 或快捷脚本）：

```bash
curl -X POST http://localhost:1111/api/tweets \
  -F "text=刚在 Rust 练习中完成了生命周期检查，感觉通透了！" \
  -F "images=@/path/to/screenshot.png"
```

服务器接收到请求后，会自动：
1. 生成精准的时间戳文件名 `YYYYMMDDHHMMSS.md`。
2. 自动存储图片至对应年月目录下的 `assets/`。
3. 写入带 Frontmatter 的 Markdown 文件并触发本地热重载！

---

## 🌐 4. 动态流聚合页展示（`/tweets/`）

构建完成后，RustPress 会在 `/tweets/` 生成类似个人主页时间线的动态瀑布流聚合页：
- 带有作者头像、昵称与发布时间。
- 文本支持完整的 Markdown 与 Emoji 表情。
- 自动提取标签并支持根据月份快速折叠与回溯。
