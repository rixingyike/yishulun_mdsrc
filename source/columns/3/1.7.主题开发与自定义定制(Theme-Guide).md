# 主题开发与自定义定制 (Theme Guide)

RustPress 采用了业界成熟、优雅且性能极高的 **Tera 模板引擎**（语法与 Jinja2 / Django 模板高度契合），结合 **Tailwind CSS** 原子化样式体系，让创作者能够以极高的自由度定制和开发独一无二的站点主题。

---

## 🎨 1. 主题目录架构规范

所有主题均存放在 `themes/<theme_name>/` 目录下（例如 `themes/default/` 或 `themes/light/`）：

```text
themes/light/
├── templates/                 # Tera HTML 模板目录
│   ├── base.html              # 根骨架模板（包含 head, nav, footer 等通用结构）
│   ├── index.html             # 默认文章列表与分页首页
│   ├── home.html              # 复合定制型首页（Hero + 简介 + 文章）
│   ├── post.html              # 常规单篇文章详情页
│   ├── columns.html           # 专栏总览与专栏主页
│   ├── doc-item.html          # 专栏章节与技术文档深度阅读页（带左侧目录树）
│   ├── archives.html          # 时间轴全量归档页
│   ├── year_archive.html      # 年份与月份聚合归档页
│   ├── tags.html              # 标签云总览页
│   ├── tag.html               # 单标签文章分页列表
│   ├── categories.html        # 全部分类层级树
│   ├── category.html          # 单分类文章分页列表
│   ├── 404.html               # 404 错误页
│   └── components/            # 可复用组件模块
│       ├── hero.html          # 首页大图/问候组件
│       ├── sidebar.html       # 侧边栏（热门文章、标签、博主名片）
│       ├── author-bio.html    # 作者卡片
│       ├── three-buttons.html # 快捷互动按钮组
│       └── toc.html           # 文章目录大纲组件
└── static/                    # 静态资产目录（自动复制到 public/static/）
    ├── css/
    │   └── main.css           # 编译生成的主题样式表
    ├── js/
    │   ├── alpinejs.min.js    # 轻量前端交互
    │   └── lunr.min.js        # 本地搜索库
    └── images/                # 头像、图标与占位图
```

## 🧩 2. Tera 模板继承与核心语法

### 基础骨架继承（`base.html`）

在子模板（如 `post.html`）中，只需通过 `{% extends "base.html" %}` 即可继承全局外壳：

```html
{% extends "base.html" %}

{% block title %}{{ page.title }} - {{ site.name }}{% endblock %}

{% block content %}
<article class="prose max-w-none">
    <h1>{{ page.title }}</h1>
    <div class="meta text-sm text-gray-500">
        <span>发布于 {{ page.date_ymd }}</span>
        {% if page.draft %}
        <span class="badge-draft">草稿</span>
        {% endif %}
    </div>

    <div class="content">
        {{ page.content | safe }}
    </div>
</article>
{% endblock %}
```

### 常用过滤器与语法速查

| 语法 / 过滤器 | 说明 | 示例 |
| :--- | :--- | :--- |
| `{{ var \| safe }}` | 渲染原始 HTML（不进行实体转义，用于输出正文） | `{{ page.content \| safe }}` |
| `{{ var \| default(value="...") }}` | 提供默认值兜底 | `{{ site.author.name \| default(value="作者") }}` |
| `{{ text \| truncate(length=80) }}` | 截取指定长度字符串 | `{{ post.description \| truncate(length=60) }}` |
| `{{ array \| slice(end=3) }}` | 数组切片操作 | `{% for p in posts \| slice(end=5) %}` |
| `{% include "components/..." %}` | 嵌入局部可复用组件 | `{% include "components/sidebar.html" %}` |

## 📦 3. 模板全局上下文变量（Context Variables）

在渲染任意模板时，RustPress 会自动注入以下丰富的上下文数据：

1. **`site`（站点全局信息）**：
   - `site.name`：站点名称
   - `site.description`：站点描述
   - `site.domain`：正式线上域名
   - `site.author.name`、`site.author.avatar`、`site.author.bio`：作者信息
   - `site.icp_license`：备案号
2. **`page`（当前文章/页面数据）**：
   - `page.title`：标题
   - `page.content`：编译后的正文 HTML
   - `page.date_ymd`：发布年月日（如 `2026-08-28`）
   - `page.create_time_hm`：发布时分（如 `14:30`）
   - `page.tags`：标签列表
   - `page.categories`：分类层级列表
   - `page.draft`：是否为草稿（`true` / `false`）
   - `page.url`：当前页面的相对访问路径
3. **`posts` / `all_posts`**：全站文章列表对象数组。
4. **`columns`**：专栏列表数据数组。
5. **`all_tags` / `all_categories`**：全站汇总的标签与分类字典。

## 🎨 4. 样式编译与 Tailwind CSS 定制

RustPress 内建了快速的样式构建命令：

```bash
# 单独编译主题 CSS
rustpress build-css

# 或者使用开发构建（自动编译 CSS 并全量生成静态页）
rustpress build-dev
```

- 如果您熟悉 Tailwind CSS，可以在主题的样式入口文件中按需添加自定义的原子类或配色变量（如极光薄荷 `cyber-mint`、深墨色 `moss-ink`、空气白 `air-bg` 等），编译后将输出优化且体积极小的 `static/css/main.css`。
