# 专栏 (Columns) 与结构化文档 (Docs) 体系

随着知识积累的加深，零散的单篇博文往往难以承载成体系的技术输出。RustPress 为此专门设计了 **专栏系统（Columns）** 与 **长篇文档体系（Docs）**，帮助创作者轻松构建媲美专业专栏平台与书籍阅读器的结构化内容。

---

## 📚 1. 专栏目录规范与结构

专栏统一存放在 `source/columns/<id>/` 目录下（例如 `source/columns/1/`、`source/columns/3/`）：

```text
source/columns/3/
├── README.md                 # 专栏总览与目录配置（核心文件）
├── assets/                   # 专栏专属资源
│   └── cover.png             # 专栏封面图片
├── 1.1.RustPress简介.md       # 专栏文章 1
├── 1.2.安装与快速上手.md      # 专栏文章 2
└── 1.3.内容组织与规范.md      # 专栏文章 3
```

---

## ⚙️ 2. 专栏 `README.md` 的 Frontmatter 配置

每个专栏根目录下的 `README.md` 是该专栏的**总控制台**，其典型配置如下：

```yaml
---
title: "RustPress 完全自修宝典"
cover: "assets/cover.png"
layout: columns
description: "从入门到精通，全面掌握基于 Rust 语言的现代纯静态博客系统构建与主题定制。"
product_id: "yishulun.com_columns_3"
price: 0.0
draft: false
tags: ["RustPress", "静态博客", "Web开发"]
catalog:
  - "1.1.RustPress简介与核心特性.md"
  - "1.2.安装、初始化与快速上手.md"
  - "1.3.内容组织与Frontmatter规范.md"
  - "1.4.专栏(Columns)与结构化文档(Docs)体系.md"
  - "1.5.短动态闲言(Tweets)与多媒体管理.md"
  - "1.6.全局配置(config.toml)与高级选项.md"
  - "1.7.主题开发与自定义定制(Theme-Guide).md"
  - "1.8.编译构建与自动化部署(CI-CD).md"
createTime: "2026-08-28 10:00:00"
---

# RustPress 完全自修宝典

这里可以写该专栏的介绍前言、作者寄语或阅读指引。正文将作为专栏主页的顶部介绍内容展示。
```

### 关键字段解析

1. **`layout: columns`**：告知模板引擎以专栏汇总版式进行渲染，自动加载专栏卡片与文章目录网格。
2. **`catalog`**：**专栏文章的排序与层级目录**。
   - RustPress 会严格按照 `catalog` 中定义的文件名次序进行排版。
   - 支持通过缩进（空格）表达多级子目录层级结构。
3. **`cover`**：专栏封面图相对路径，通常为 `assets/cover.png`。
4. **`draft`**：专栏上线状态开关。若设置为 `true`，生产构建时整部专栏及其所有下属子文章均会被自动隐藏。

## 🛠️ 3. 专栏自动化利器：目录与封面脚本

在日常写作中，随着篇章增加，手动维护 `README.md` 的 `catalog` 列表以及为每个专栏制作封面图往往耗时费力。RustPress 项目提供了两个高效的自动化辅助脚本：

### 目录自动增量更新脚本（`make_catalog.sh`）

```bash
# 自动扫描专栏 3 下的所有 .md 文件，保留已有排序，按创建时间追加新文章并更新 README.md
./make_catalog.sh 3

# 批量为所有专栏自动整理更新目录
./make_catalog.sh --all
```

- **特性**：已手动调整好的次序绝不改动，新加入的文件根据 Frontmatter 的 `createTime` 与自然数序号智能追加到 `catalog` 中。

### 专栏封面自动生成脚本（`make_cover.sh`）

```bash
# 自动提取专栏 3 的标题与作者，生成高清封面图 assets/cover.png
./make_cover.sh 3

# 批量一键为所有专栏生成封面
./make_cover.sh
```

- **特性**：自动根据专栏标题、底板主题色板（8 组优雅浅色）与作者署名生成标准 800×450 / 900×500 像素的高清封面图。

## 📖 4. 专栏文章阅读体验（`doc-item.html`）

当读者点击进入专栏的某篇文章时，RustPress 会采用专业的长文/文档阅读版式进行渲染：

- **左侧响应式目录树**：高亮当前阅读章节，支持折叠与快速跳转。
- **面包屑导航**：`首页 / 专栏 / 专栏名称 / 当前文章`，层级清晰。
- **前后篇连载翻页**：底部自动提供“上一篇”与“下一篇”快捷链接，提升连贯沉浸阅读体验。
