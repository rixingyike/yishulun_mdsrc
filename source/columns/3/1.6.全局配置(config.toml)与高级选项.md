# 全局配置 (config.toml) 与高级选项

RustPress 的全局配置集中在根目录下的 `config.toml`（亦支持在 `source/config.toml` 存放）。通过简洁明了的 TOML 语法，您可以轻松自定义站点基础信息、作者社交网络、主题选择与高级 SEO 设置。

---

## ⚙️ 1. `config.toml` 配置模板全景解析

以下是一份标准完整的 `config.toml` 示例及字段注释：

```toml
# ==========================================
# 站点基础信息配置
# ==========================================
[site]
name = "一树仑"                                # 网站主标题
description = "一花一世界，一树一菩提。"          # 站点副标题与 Meta Description
author = "金石碼农"                            # 站长/默认作者名称
logo = "/static/images/avatar.png"           # 顶部导航栏 Logo
favicon = "/static/images/favicon.ico"       # 浏览器标签页 Favicon

# 生产环境公开显示的正式域名（用于生成 RSS、Sitemap 与 Canonical 链接）
domain = "https://yishulun.com"

# 本地或当前构建的基础 URL（本地预览通常为 http://localhost:1111）
base_url = "https://yishulun.com"

# 备案与合规信息
icp_license = "京ICP备14007000号-8"
start_year = 2024                             # 底部版权起始年份（如 2024 - 2026）

# ==========================================
# 作者信息与社交档案
# ==========================================
[site.author]
name = "金石碼农"
avatar = "/static/images/avatar.png"
bio = "独立开发者，热爱 Rust、前端工程与文学创作。"
email = "contact@yishulun.com"
github = "https://github.com/rixingyike"
twitter = "https://twitter.com/your_handle"

# ==========================================
# 主题配置
# ==========================================
[theme]
name = "light"                               # 当前激活的主题目录名（例如 "default" 或 "light"）

# ==========================================
# 分类法（Taxonomies）配置
# ==========================================
[taxonomies]
categories = "categories"
tags = "tags"
```

## 🔍 2. 自动化产物：SEO、Sitemap、RSS 与搜索索引

每次执行 `rustpress build` 时，系统会自动根据配置生成一系列高质量的标准静态索引：

### 1. 全文搜索索引（`search.json`）
- RustPress 会自动提取每篇文章的正文纯文本、标题、标签与分类，构建轻量级的 **Lunr.js** 搜索索引文件 `search.json`。
- 前端通过异步加载实现即时检索、高亮匹配，且不需要任何后端数据库支持。

### 2. RSS 订阅源（`rss.xml`）
- 严格遵循 RSS 2.0 / Atom 规范，正文链接与媒体资源自动补全为 `config.toml` 中配置的绝对域名 `domain`，便于各类 Feed 阅读器正常抓取。

### 3. 搜索引擎地图（`sitemap.xml`）与 `robots.txt`
- 包含所有公开文章、专栏、标签与分类页面的完整 URL 清单与最后更新时间戳，方便百度、Google 等爬虫完整收录。

## 🛡️ 3. 草稿模式（Draft Mode）行为机制

为了避免写到一半的文章意外泄露到生产线上，RustPress 设计了严谨的草稿隔离机制：

- **标记草稿**：在文章或专栏的 Frontmatter 中设置 `draft: true`。
- **生产构建（`rustpress build`）**：
  - 当使用正式线上域名且未显式指定 `--drafts` 时，**所有标记为草稿的文章与专栏将被绝对剔除**，不会生成任何 HTML 文件，也不会进入 RSS、Sitemap 或搜索索引。
- **本地开发预览（`rustpress serve` / `localhost`）**：
  - 自动识别为本地开发环境，**完整放行草稿内容**。
  - 在专栏列表、专栏文章及详情页中自动附带黄色 <kbd style="background:#fef3c7;color:#92400e;border:1px solid #fcd34d;padding:2px 6px;border-radius:4px;font-size:12px;">草稿</kbd> 视觉徽章，方便创作者在本地直观预览校对。

## 📊 4. 内部构建状态表（`build.toml`）

在 `source/` 目录下，RustPress 会维护一个内部状态文件 `build.toml`：
- **记录增量编译时间戳**：`last_build_time` 用于对比文章文件的修改时间。
- **首页侧边栏数据缓存**：包含全站热门标签统计、分类计数与最新精选文章，避免每次渲染页面时重复耗时遍历。
- 若需要强制重置统计数据，只需运行命令：`rustpress build-sidebar`。
