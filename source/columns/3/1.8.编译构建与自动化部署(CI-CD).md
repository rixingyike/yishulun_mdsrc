# 编译构建与自动化部署 (CI/CD)

由于 RustPress 生成的是百分之百的纯静态文件（HTML/CSS/JS/JSON/XML），您可以将产物无缝托管在任何静态托管服务上，包括 **GitHub Pages**、**Vercel**、**Cloudflare Pages**、**Netlify** 或自建的 **Nginx / Caddy** 服务器。

本章将介绍如何配置 GitHub Actions 工作流，实现“本地一键 `git push`，云端自动编译并发布上线”。

---

## 🛠️ 1. 本地构建命令流程回顾

| 场景 | 推荐命令 | 说明 |
| :--- | :--- | :--- |
| **日常撰写与预览** | `rustpress serve` | 启动本地预览服务器（`http://localhost:1111`），修改即看，包含草稿。 |
| **本地生产发布测试** | `rustpress build --output-dir public` | 模拟生产环境全量构建，自动隐藏 `draft: true` 草稿。 |
| **大型博客快速增量** | `rustpress build --incremental` | 毫秒级增量编译，仅重新渲染修改过的文件。 |

## 🚀 2. GitHub Actions 自动化发布实战（GitHub Pages）

在博客仓库根目录下创建文件 `.github/workflows/deploy.yml`：

```yaml
name: Deploy RustPress Blog to GitHub Pages

on:
  push:
    branches:
      - main                      # 监听 main 分支的提交触发自动构建
  workflow_dispatch:              # 支持在 GitHub 页面上手动点击触发

# 设置 GITHUB_TOKEN 权限以允许部署到 GitHub Pages
permissions:
  contents: read
  pages: write
  id-token: write

# 保证同一时间只有一个部署作业在运行
concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build-and-deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      # 1. 检出仓库代码
      - name: Checkout Repository
        uses: actions/checkout@v4

      # 2. 安装 Rust 工具链
      - name: Set up Rust
        uses: dtolnay/rust-toolchain@stable

      # 3. 缓存 Cargo 依赖与二进制，加速云端构建
      - name: Cache Cargo Dependencies
        uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/bin/
            ~/.cargo/registry/index/
            ~/.cargo/registry/cache/
            ~/.cargo/git/db/
            target/
          key: ${{ runner.os }}-cargo-rustpress-${{ hashFiles('**/Cargo.lock') }}
          restore-keys: |
            ${{ runner.os }}-cargo-rustpress-

      # 4. 安装 RustPress 工具
      - name: Install RustPress
        run: |
          if ! command -v rustpress &> /dev/null; then
            cargo install rustpress
          fi

      # 5. 执行生产环境构建
      - name: Build Static Site
        run: |
          rustpress --md-dir source build --output-dir public

      # 6. 配置 GitHub Pages
      - name: Setup Pages
        uses: actions/configure-pages@v4

      # 7. 上传生成的 public 静态目录
      - name: Upload Artifacts
        uses: actions/upload-pages-artifact@v3
        with:
          path: "public"

      # 8. 部署到 GitHub Pages
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

### 开启 GitHub Pages 权限设置
1. 打开您的 GitHub 仓库页面，点击 **Settings** -> **Pages**。
2. 在 **Build and deployment** 下方的 **Source** 选择 **GitHub Actions**。
3. 以后每次 `git push` 提交新的文章，GitHub 将在约 30 秒内全自动完成编译并更新上线！

## ☁️ 3. 部署到其他平台

### 部署到 Vercel / Netlify / Cloudflare Pages

在平台的控制台中创建新项目并连接 GitHub 仓库，填写以下配置：
- **Build Command（构建命令）**：
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y && source $HOME/.cargo/env && cargo install rustpress && rustpress --md-dir source build --output-dir public
  ```
- **Output Directory（输出目录）**：`public`

### 部署到自建 Nginx / Docker 服务器

Nginx 基础配置示例：

```nginx
server {
    listen 80;
    server_name yishulun.com;

    root /var/www/yishulun/public;
    index index.html;

    # 静态资源长期缓存
    location /static/ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }

    # 404 错误页定向
    error_page 404 /404.html;
    location = /404.html {
        internal;
    }

    location / {
        try_files $uri $uri/ =404;
    }
}
```
