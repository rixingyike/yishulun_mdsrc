# 安装、初始化与快速上手

本章将介绍如何在 macOS、Linux 或 Windows 环境中安装 RustPress，并使用命令行快速创建一个现代化的静态博客站点。

---

## 📦 1. 安装 RustPress

### 方式一：通过 Cargo 一键安装（推荐）

如果您的系统中已经安装了 Rust 工具链（可通过 [rustup.rs](https://rustup.rs/) 安装），只需在终端中运行一行命令：

```bash
cargo install rustpress
```

Cargo 会自动从 [Crates.io](https://crates.io/crates/rustpress) 下载最新源码并在本机编译，完成后 `rustpress` 命令将自动加入系统 `PATH`。

验证安装是否成功：

```bash
rustpress --version
```

### 方式二：克隆源码编译（开发最新版）

若您希望体验最新的开发分支或参与贡献：

```bash
# 1. 克隆代码仓库
git clone https://github.com/rixingyike/rustpress.git
cd rustpress

# 2. 编译发布版二进制
cargo build --release

# 3. 将二进制移动至系统 PATH 路径（例如 ~/.cargo/bin）
cp target/release/rustpress ~/.cargo/bin/
```

## 🚀 2. 创建与初始化博客

RustPress 提供了两条直观的脚手架命令来快速启动新项目：

### 选项 A：从零创建全新博客项目（`rustpress new`）

如果您想在一个全新的独立目录下创建站点：

```bash
# 创建名为 my-blog 的新项目
rustpress new my-blog

# 进入项目目录
cd my-blog
```

`rustpress new` 会为您生成标准的文件骨架，包括示例文章、配置文件、基础主题以及用于一键部署的 GitHub Action 工作流脚本。

### 选项 B：在已有 Markdown 目录无损初始化（`rustpress init`）

如果您已经有了一个存有大量 Markdown 文件的目录，只需在该目录下执行：

```bash
cd /path/to/my-markdown-repo
rustpress init
```

`rustpress init` 会智能识别当前目录结构，自动补齐缺失的主题目录、`config.toml` 配置模板、`build.toml` 构建记录以及示例页面，**绝不会覆盖或破坏您现有的任何 Markdown 文章**。

## 📂 3. 标准项目目录结构解析

初始化完成后，一个标准的 RustPress 项目结构如下所示：

```text
my-blog/
├── config.toml           # 全局核心配置文件（站点信息、主题、社交等）
├── source/               # Markdown 内容源目录（存放所有正文与资产）
│   ├── config.toml       # （可选）针对 source 目录的覆盖配置
│   ├── build.toml        # 内部编译状态记录（增量构建时间戳、侧边栏缓存）
│   ├── 2026/             # 按年份归档的博文目录
│   │   ├── 01.md
│   │   └── assets/       # 文章插图与多媒体资源
│   ├── columns/          # 专栏目录（按专栏 ID 分组）
│   │   └── 1/
│   │       ├── README.md # 专栏元数据与目录配置文件
│   │       └── ...
│   ├── tweets/           # 短动态/闲言目录
│   ├── about.md          # 关于页面
│   └── friends.md        # 友情链接页面
├── themes/               # 主题模板与样式目录
│   ├── default/          # 默认主题
│   │   ├── templates/    # Tera 模板文件（base.html, post.html 等）
│   │   └── static/       # 静态 CSS / JS / 图标
│   └── light/            # 极光浅色主题
└── public/               # 构建生成的最终纯静态产物（可直接部署）
```

## 💻 4. 启动本地实时预览服务器

RustPress 内建了基于 Axum 的开发服务器，支持 **边改边看（Live Reload 热重载）**：

```bash
# 启动本地预览服务器（默认端口 1111）
rustpress serve
```

终端将输出服务地址，并在默认浏览器中自动打开：
👉 `http://localhost:1111`

### 常用命令参数速查表

| 命令 / 参数 | 说明 | 示例 |
| :--- | :--- | :--- |
| `rustpress serve` | 启动带热重载的本地预览服务（默认端口 1111） | `rustpress serve --port 8080` |
| `rustpress build` | 生产环境构建（仅生成静态 HTML，速度最快） | `rustpress build --output-dir public` |
| `rustpress build --incremental` | 生产环境增量构建（仅重新编译修改的文章） | `rustpress build --incremental` |
| `rustpress build-dev` | 开发环境全量构建（包含编译主题 Tailwind CSS） | `rustpress build-dev` |
| `rustpress build-css` | 单独重新编译主题 CSS 样式表 | `rustpress build-css` |
