# RustPress 完全自修宝典

欢迎阅读 **RustPress** 官方深度使用指南！

**RustPress**（[GitHub 仓库](https://github.com/rixingyike/rustpress) | [Crates.io 类库](https://crates.io/crates/rustpress)）是一款由 Rust 语言精心打造的纯静态、高性能、零后端依赖的现代静态博客程序。

本专栏将从设计哲学、安装上手、内容组织、专栏与文档体系，一直到全局配置、主题二次开发以及 CI/CD 自动化持续部署，为您提供全面、系统、清晰的实践指导。
