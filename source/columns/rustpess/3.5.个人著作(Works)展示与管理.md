# 个人著作 (Works) 展示与管理

对于撰写过实体书、电子书或出版课程的技术作者而言，拥有一个专属的 **著作与出版物（Works）展示系统** 能够全方位沉淀个人学术成果与行业影响力。

RustPress 专门设计了 `works` 内容模型，支持立体化书籍封面、出版信息归档、购买直达链接以及图书勘误大纲。

---

## 一、著作目录结构规范

所有著作存放在 `source/works/` 目录下：

```text
source/works/
├── README.md                 # 著作总览页（介绍个人出版历程）
├── assets/                   # 图书封面专属高清图
│   ├── minigame.png
│   └── miniprogram-0-1.png
├── miniprogram-0-1.md        # 单部著作 1
└── minigame-dev.md           # 单部著作 2
```

---

## 二、单部著作 Markdown 规范

新建一个著作 Markdown 文件（例如 `source/works/miniprogram-0-1.md`）：

```yaml
---
title: "小程序从0到1"
subtitle: "微信全栈开发实战"
layout: work
cover: "assets/miniprogram-0-1.png"
publisher: "机械工业出版社"
year: 2017
url: "https://e.jd.com/30401467.html"
description: "从零开始学习微信小程序开发，系统覆盖前端组件、网络通信、后端服务及云开发一体化实战。"
createTime: 2025-11-05 08:00:00
comments: false
---
```

### 属性字段说明表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | `String` | 书籍/著作名称。 |
| `subtitle` | `String` | 副标题或定位（如“微信全栈开发实战”）。 |
| `layout` | `String` | 固定指定为 `work`。 |
| `cover` | `String` | 图书立体封面图相对路径。 |
| `publisher`| `String` | 出版社或发行机构（例如“机械工业出版社”）。 |
| `year` | `Integer` | 出版年份（如 `2017`），用于年份归档与排序。 |
| `url` | `String` | 官方购买、在线试读或电子书直链。 |
| `description`| `String`| 一句话推荐语与内容摘要。 |

## 三、著作总览与单品详情页体验

1. **著作汇总页（`/w/`）**：以书架式卡片网格呈现，展示书本封面、出版社徽章、出版年份与“立即购买/阅读”按钮。
2. **书籍详情页（`/w/miniprogram-0-1.html`）**：左侧展示立体书封与元数据卡片，右侧展示完整的书籍介绍、读者书评、章节目录及后续勘误更新。
