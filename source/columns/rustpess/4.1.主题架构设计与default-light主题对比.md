# 主题架构设计与 default/light 主题对比

RustPress 采用了一套兼具极致性能与高度可扩展性的主题系统。底层基于 Rust 高性能模板引擎 **Tera**（语法与 Jinja2 / Django 模板高度一致），结合现代前端事实标准的 **Tailwind CSS** 原子化样式库，彻底摆脱了传统静态博客笨重臃肿的运行时依赖。

---

## 一、主题标准目录架构

所有主题均存放在 `themes/<theme_name>/` 目录下。一个规范的主题包目录结构如下：

```text
themes/light/
├── templates/                 # Tera HTML 模板目录
│   ├── base.html              # 全站基础骨架模板（Header、Meta、Navigation、Footer）
│   ├── index.html             # 标准博文分页列表页
│   ├── home.html              # 复合定制型首页（Hero 问候大图 + 最新动态 + 文章）
│   ├── post.html              # 单篇博文详情页
│   ├── columns.html           # 专栏总览与专栏主页
│   ├── doc-item.html          # 专栏章节阅读页（带左侧目录树）
│   ├── ...                    # 其他内容模型模板
│   └── components/            # 可复用局部组件
│       ├── hero.html          # 首页大图问候组件
│       ├── sidebar.html       # 侧边栏（热门标签、分类、精选文章、博主名片）
│       ├── author-bio.html    # 作者卡片与打赏组件
│       └── toc.html           # 文章目录大纲
├── src/                       # 样式与前端源码
│   └── input.css              # Tailwind CSS 源码入口
├── static/                    # 静态资产目录（构建时自动完整复制至 public/static/）
│   ├── css/
│   │   └── main.css           # Tailwind 编译产出的最终优化 CSS
│   ├── js/
│   │   ├── alpinejs.min.js    # 轻量前端交互驱动（下拉菜单、移动端抽屉）
│   │   └── lunr.min.js        # 客户端离线全文搜索库
│   └── images/                # 默认头像、占位图与背景
├── tailwind.config.js         # Tailwind CSS 主题配色与断点配置
├── postcss.config.js          # PostCSS 插件配置
└── package.json               # 主题样式编译依赖定义
```

## 二、内置主题全景对比：default vs light

RustPress 开箱内置了两套经过专业设计打磨的官方主题，满足不同创作者的视觉审美与内容呈现诉求：

### 1. `default` 主题（经典科技与沉稳布局）
- **设计风格**：经典科技风，强调信息密度与多栏层次感。
- **视觉特征**：深色调导航、清晰的边框分割线、结构严谨的侧边栏卡片。
- **适用场景**：适合内容品类丰富、多分类、多标签的大型技术博客、团队知识库与综合性开发者门户。

### 2. `light` 主题（现代极简与极光美学）
- **设计风格**：极简现代、清爽通透，具备大面积的优雅留白与呼吸感排版。
- **视觉特征**：
  - 精选极光薄荷色（`cyber-mint`）与深墨色（`moss-ink`）配色。
  - 柔和的阴影（Soft Shadows）、细边框与圆角卡片。
  - 高度优化的阅读字体排版（Typography），中文正文字距与行高经过精细校准。
- **适用场景**：适合个人深度长文写作、技术专栏连载、现代极客与设计美学追求者。

## 三、主题快速切换

在 `config.toml` 中，仅需修改一行配置即可实现主题秒级热切换：

```toml
[theme]
name = "light"  # 可选: "default" 或 "light"（或您的自定义主题名）
```

保存文件后，本地开发服务器将自动重新渲染，并在浏览器中无缝展现新主题效果。
