# 友情链接 (Friends) 添加与管理

与优秀的独立博主和技术同行交换友情链接，是独立博客相互连接、形成去中心化知识网络的重要方式。

RustPress 提供了高度结构化的 **友情链接（Friends）模型**，支持卡片式网格排版、头像自动缓存与排序控制。

---

## 一、友链目录规范

所有友情链接存放在 `source/friends/` 目录下：

```text
source/friends/
├── README.md                 # 友链总览页与申请规范说明（必须）
├── assets/                   # 友链专属头像与图标
│   ├── tvp.ico
│   ├── rust-lang_logo.png
│   └── friend-avatar.jpg
├── 1.md                      # 单个友链定义文件
├── 2.md
└── 3.md
```

---

## 二、单条友链 Markdown 格式规范

在 `source/friends/` 下新建一个 Markdown 文件（如 `source/friends/1.md`），填入 Frontmatter 元数据：

```yaml
---
title: "腾讯云最具价值专家 (TVP)"
slug: "tvp"
link: "https://cloud.tencent.com/tvp"
description: "腾讯云最具价值专家计划，汇聚行业顶尖技术精英与布道者。"
avatar: "assets/tvp.ico"
domain: "cloud.tencent.com"
weight: 1
layout: friend
createTime: 2025-11-05 08:00:00
---
```

### 属性字段说明表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | `String` | 友链网站名称或博主昵称。 |
| `link` | `String` | 友链目标跳转 URL。 |
| `description` | `String` | 友链网站一句话简述（展示于卡片下方）。 |
| `avatar` | `String` | 友链头像路径，可为 `assets/` 相对路径或外部绝对 URL。 |
| `domain` | `String` | 友链主域名标识。 |
| `weight` | `Integer` | 排序权重，数字越小排在越前面。 |
| `layout` | `String` | 固定指定为 `friend`。 |

---

## 三、友链总览与申请说明（`source/friends/README.md`）

`source/friends/README.md` 是友情链接页面的介绍头部，您可以在其中写明本站信息与互换友链的要求：

```yaml
---
title: "友情链接"
layout: friends
description: "海内存知己，天涯若比邻。欢迎志同道合的技术博主交换友链。"
createTime: 2025-11-05 08:00:00
---
```

## 四、前端卡片式呈现效果

构建完成后，访问 `/f/`（即友情链接主页）：
- 顶部展示 `README.md` 的申请说明与本站档案。
- 下方以响应式网格渲染所有友链卡片（圆形头像、加粗网站名、悬浮阴影放大特效及一键跳转）。
- 底部可选加载 Giscus 评论区，方便访客直接提交友链申请！
