# 安装与本地开发预览

**RustPress** 是基于 Rust 语言构建的纯静态、高性能、零后端依赖的现代静态博客与内容发布引擎。本篇将详细介绍如何在 macOS、Linux 或 Windows 环境中安装 RustPress，初始化项目并在本地启动热重载开发服务器。

---

## 一、环境准备

在安装 RustPress 前，请确保本地已安装 Rust 官方工具链。如果尚未安装，可以通过官方推荐脚本一键配置：

```bash
# macOS / Linux 安装命令
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证 Rust 与 Cargo 是否安装成功
rustc --version
cargo --version
```

---

## 二、安装 RustPress 的两种方式

### 方式 1：直接通过 Cargo 一键安装类库（推荐）

这是最简便快捷的安装方式。Cargo 会从 [Crates.io](https://crates.io/crates/rustpress) 自动下载最新的稳定源码并在本地编译成单一二进制文件：

```bash
# 安装最新稳定版 RustPress
cargo install rustpress --locked
```

> **提示**：`--locked` 参数可确保使用经过验证的依赖锁定版本，避免上游依赖库更新导致的构建异常。

安装完成后，Cargo 会自动将二进制程序放入 `~/.cargo/bin` 目录中。检查是否安装成功：

```bash
rustpress -V
# 输出示例：rustpress 0.1.21
```

---

### 方式 2：从 GitHub 源码编译安装（开发者模式）

如果您需要使用最新的开发分支、参与代码贡献，或对 RustPress 核心进行二次开发定制，可以直接克隆源码进行本地编译：

```bash
# 1. 克隆代码仓库
git clone https://github.com/rixingyike/rustpress.git
cd rustpress

# 2. 编译发布版二进制（启用最高性能编译优化）
cargo build --release

# 3. 将编译好的二进制复制至系统环境变量 PATH 目录中
cp target/release/rustpress ~/.cargo/bin/

# 4. 验证版本
rustpress -V
```

## 三、项目初始化与目录规范

安装完成后，您可以通过脚手架命令快速搭建博客站点。

### 1. 全新项目创建（`rustpress new`）

如果您是从零开始创建全新的博客仓库：

```bash
# 创建名为 my-blog 的新博客
rustpress new my-blog

# 进入博客目录
cd my-blog
```

### 2. 在已有 Markdown 仓库中初始化（`rustpress init`）

如果您已经有积累的 Markdown 笔记或从其他静态生成器（如 Hexo, Hugo, VitePress）迁移而来，只需进入该目录执行：

```bash
cd /path/to/my-notes
rustpress init
```

`rustpress init` 具有**无损增强**特性：它会自动补齐 `config.toml` 配置文件、`themes/` 主题目录以及静态资源骨架，**绝对不会修改或覆盖您现有的任何 Markdown 内容**。

---

## 四、标准项目目录结构

执行初始化后，标准的 RustPress 项目结构如下：

```text
my-blog/
├── config.toml           # 站点核心全局配置文件
├── source/               # Markdown 内容源目录
│   ├── 2026/             # 按年份归档的日常博文
│   │   ├── 01.md
│   │   └── assets/       # 文章插图
│   ├── columns/          # 专栏与体系化课程目录
│   │   └── rustpress/    # 具体专栏，例如 rustpress
│   │       ├── README.md # 专栏总览与目录配置
│   │       └── ...
│   ├── tweets/           # 短动态与闲言目录（按年月分层）
│   ├── friends/          # 友情链接 Markdown 目录
│   ├── works/            # 著作与出版物
│   ├── projects/         # 开源项目与作品
│   ├── about.md          # 作者个人简介
│   ├── CNAME             # 独立域名配置文件
│   └── ads.txt           # 谷歌广告认证文件
├── themes/               # 主题模板与样式目录
│   ├── default/          # 默认主题
│   └── light/            # 极简浅色主题
└── public/               # 构建生成的最终纯静态产物（部署目标目录）
```

## 五、启动本地开发服务器与热重载

RustPress 内置了基于高性能异步网络框架的本地预览服务器，支持 **Live Reload（实时热重载）**。

### 1. 使用 rustpress serve 命令

在项目根目录下直接运行：

```bash
# 启动本地开发服务（默认监听端口 1111）
rustpress serve

# 或者指定 Markdown 源目录、自定义端口（1111）及输出目录（public）
rustpress -m source serve --port 1111 --output-dir public
```

服务启动后，打开浏览器访问：
👉 **`http://localhost:1111`**

只要您在 `source/` 目录下修改或保存任何 Markdown 文件，浏览器将毫秒级自动刷新，无需手动点击重载！

### 2. 使用快捷脚本启动（针对团队与工程化管理）

在生产级项目中，通常配合后台守护与进程管理脚本更稳健：

```bash
# 启动开发服务器（支持自动端口清理与后台驻留）
./start-dev.sh

# 查看当前开发服务器运行状态
./status-dev.sh

# 停止开发服务器
./stop-dev.sh
```

## 六、安装成功判定标准

当满足以下条件时，即证明您的 RustPress 本地环境已**完全安装配置成功**：

1. 终端执行 `rustpress -V` 能够正常输出版本号。
2. 执行 `rustpress serve`（或 `./start-dev.sh`）后，终端无报错。
3. 打开浏览器访问 `http://localhost:1111`，能够流畅浏览首页、专栏文章列表与作者主页。
4. 本地修改任意 Markdown 文件并保存，浏览器页面能够实时热更新展现最新内容。

作者的博客艺述论（[yishulun.com](https://yishulun.com)）即是由 RustPress 构建的，目前使用的是 light theme，打开即能预览实际运动效果。
