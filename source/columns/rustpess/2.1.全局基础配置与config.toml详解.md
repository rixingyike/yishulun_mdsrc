# 全局基础配置与 config.toml 详解

RustPress 的所有核心行为、站点元数据、作者社交信息、导航菜单与功能开关，均由统一的配置文件 **`config.toml`** 控制。

本篇将全面拆解 `config.toml` 的每一个配置区块与参数含义，帮助您快速打造符合个人品牌调性的独立站点。

---

## 一、配置文件位置与加载优先级

RustPress 支持在以下两个位置读取配置文件：
1. **根目录**：`./config.toml`（全局构建默认配置）
2. **源目录**：`./source/config.toml`（优先覆盖或独立内容仓库模式）

当使用 `rustpress -m source serve` 或 `rustpress -m source build` 时，系统会优先读取 `source/config.toml`。

---

## 二、`config.toml` 完整配置全貌

一份标准的完整 `config.toml` 文件结构如下：

```toml
# ==============================================================================
# 1. 站点核心元数据 [site]
# ==============================================================================
[site]
name = "艺述论"                                # 网站主名称（展示于导航栏与浏览器标题）
description = "一花一世界，一树一菩提。"          # 站点副标题、Slogan 及 SEO Meta 描述
author = "金石碼农"                            # 站长/默认作者署名
logo = "/static/images/avatar.png"           # 顶部导航栏显示的 Logo 图片路径
favicon = "/static/images/favicon.ico"       # 浏览器标签页 Favicon 图标
domain = "https://yishulun.com"              # 生产环境正式公开域名（用于生成 RSS、Sitemap 与 Canonical 绝对链接）
base_url = "http://localhost:1111"           # 当前构建的基础 URL（本地开发预览填 localhost，上线 CI/CD 填正式域名）
dev_domains = ["dev.yishulun.com", "localhost", "127.0.0.1", "0.0.0.0", "::1"] # 本地/测试域名（在这些域名下：展示草稿标识、首页显示短动态发布框）
icp_license = "京ICP备14007000号-8"           # 网站备案号（展示于页脚）
start_year = 2002                            # 创站年份（页脚自动生成 © 2002 - 2026）

# ==============================================================================
# 2. 激活主题配置 [theme]
# ==============================================================================
[theme]
name = "light"                               # 激活的主题名称，对应 themes/ 下的目录名（如 "default" 或 "light"）

# ==============================================================================
# 3. 作者档案与展示信息 [author]
# ==============================================================================
[author]
name = "金石碼农"                            # 作者姓名
maxim = "势利纷华，不近者为洁；智械机巧，不知者为高。" # 座右铭/名言
bio = "大学计算机讲师，腾讯云最具价值专家（TVP），多本计算机畅销书作者。" # 个人简述

# ==============================================================================
[social]
github = "https://github.com/rixingyike"     # GitHub 主页链接
twitter = "https://x.com/jinshimanong"       # Twitter / X 主页链接
youtube = "https://youtube.com/@yishulun"    # YouTube 频道

# ==============================================================================
# 5. 首页与版块展示设置 [homepage]
# ==============================================================================
```

## 三、关键参数深度解析与避坑指南

### 1. `domain` 与 `base_url` 的区别
- **`domain`**：必须为带协议头的正式线上域名（如 `https://yishulun.com`）。用于生成 RSS 订阅里的绝对文章地址、Sitemap 中的永久链接以及 Open Graph 社交分享卡片。
- **`base_url`**：当前编译时的环境基准地址。本地开发时通常设为 `http://localhost:1111`，使得本地静态资源的相对路径解析完全正常。

### 2. `show_hero` 在不同主题下的展示行为
- **`default` 主题**：渲染全屏渐变图文 Hero 区块，展示 `hero_background` 背景大图、`hero_title` 主标题、`hero_subtitle` 副标题以及两个交互 CTA 按钮（浏览文章 / 了解作者）。
- **`light` 主题**：渲染为现代极简风格的“座右铭/个人信仰”名言卡片，展示作者座右铭 `author.maxim` 与“关于作者”引导链接。
- **关闭 Hero**：只要在 `[homepage]` 下设置 `show_hero = false`，无论哪个主题都会彻底隐藏首页顶部的 Hero 区块，直接呈现博文列表。

### 3. `posts_per_page` 分页容量与倒分页机制
`posts_per_page` 在 RustPress 编译生成引擎中起到极其关键的分页控制作用：
- **首页文章列表**：`[homepage] posts_per_page = 8` 决定首页及后续分页（`index2.html`、`index3.html`...）每页容纳的博文数量。
- **分类与标签页**：`[categories] posts_per_page` 与 `[tags] posts_per_page` 分别控制各个分类和标签列表页的每页容量（未配置时自动回退继承首页设置）。
- **倒分页算法基数**：RustPress 独创的倒分页算法在为单篇文章计算其所在的历史归档分页 URL 时，直接以 `posts_per_page` 为切分基数，确保老页面的静态 URL 与内容永久稳固不变。

### 4. 导航菜单权重 `weight`
导航菜单支持任意增删改。RustPress 会自动按照 `weight` 从小到大的顺序在网页顶部横向排列导航项目。

### 5. 主题一键热切换
只需将 `[theme]` 下的 `name` 从 `"default"` 改为 `"light"`，保存文件即可触发热重载，站点风格瞬间无缝转换。
