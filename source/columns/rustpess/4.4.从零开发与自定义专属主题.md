# 从零开发与自定义专属主题

如果您希望打造独一无二的视觉风格，或者为公司/技术社区构建专属品牌的知识门户，RustPress 提供了极为顺畅的主题开发体验。

本篇将带您一步步从零构建属于自己的专属主题（Custom Theme），并掌握 Tailwind CSS 样式编译与热重载调试全流程。

---

## 一、主题创建与快速起步

最推荐的主题起步方式是以官方成熟的 `themes/light` 或 `themes/default` 作为母版进行派生定制：

```bash
# 1. 复制现有主题骨架作为新主题基底
cp -r themes/light themes/my-theme

# 2. 进入新主题目录
cd themes/my-theme
```

---

## 二、在 `config.toml` 中激活新主题

编辑站点根目录的 `config.toml`，将主题名称切换为您的新主题目录名：

```toml
[theme]
name = "my-theme"
```

保存后，RustPress 的所有页面将自动从 `themes/my-theme/templates/` 目录加载模板！

---

## 三、Tailwind CSS 配色与字体深度定制

在新主题目录下的 `tailwind.config.js` 中，您可以自由定义站点的调色板、字号阶梯与暗黑模式规则：

```javascript
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./templates/**/*.html",
    "../../source/**/*.md"
  ],
  theme: {
    extend: {
      colors: {
        // 自定义品牌主色调
        brand: {
          50:  '#f0fdf4',
          100: '#dcfce7',
          500: '#22c55e',
          600: '#16a34a',
          900: '#14532d',
        },
        // 自定义极光色板
        accent: '#38bdf8',
      },
      fontFamily: {
        // 中西文优化字体栈
        sans: [
          '-apple-system',
          'BlinkMacSystemFont',
          '"Segoe UI"',
          'Roboto',
          '"Noto Sans SC"',
          'sans-serif'
        ],
        mono: [
          '"JetBrains Mono"',
          '"Fira Code"',
          'monospace'
        ]
      }
    },
  },
  plugins: [
    require('@tailwindcss/typography'),
    require('@tailwindcss/forms'),
  ],
}
```

## 四、编写与覆写核心模板

进入 `themes/my-theme/templates/`，您可以自由修改：

1. **`base.html`**：
   - 修改 Header 的导航栏布局，添加全站通知横幅（Banner）。
   - 在 Footer 中增加社交图标或友情链接入口。
2. **`components/hero.html`**：
   - 打造具有个人特色的首页动态打字机特效或 3D 粒子背景。
3. **`post.html`**：
   - 定制文章正文的行高、字体颜色，添加一键复制 Markdown 或打赏弹窗。

---

## 五、样式编译与热重载调试

RustPress 内建了快速的样式构建命令：

```bash
# 方式 1：使用 rustpress 编译 CSS
rustpress build-css

# 方式 2：使用开发全量构建（包含编译 Tailwind CSS 与生成静态 HTML）
rustpress build-dev

# 方式 3：通过 npm 监听 Tailwind 样式变更
npm run dev:css
```

在日常开发中，建议开启两块终端：
- 终端 1 运行 `rustpress serve`（监听 Markdown 与 HTML 模板热更新）。
- 终端 2 运行 `npx tailwindcss -i ./src/input.css -o ./static/css/main.css --watch`（实时监听 CSS 样式类变化）。

任何原子类的添加或 HTML 模板的修改，都将毫秒级直观反映在浏览器中！

---

## 六、主题发布与独立维护

当您打磨好一款满意的主题后，可以将其作为一个独立的 Git 仓库进行开源：
1. 将主题仓库提交至 GitHub（如 `github.com/your-name/rustpress-theme-awesome`）。
2. 在其他博客项目中，以 Git Submodule 形式引入：
   ```bash
   git submodule add https://github.com/your-name/rustpress-theme-awesome.git themes/awesome
   ```
3. 在 `config.toml` 中设置 `[theme] name = "awesome"`，即可一键使用！
