# 谷歌统计 (Google Analytics) 配置

对于独立博客创作者而言，了解网站的访问量、用户来源国家/地区、最受欢迎的热门文章以及读者停留时长是极为重要的。**Google Analytics 4（GA4）** 是全球目前最主流、功能强大且完全免费的网站数据分析工具之一。

RustPress 内建了对 GA4 的原生无侵入支持，只需在 `config.toml` 中填入媒体资源衡量 ID，即可全自动完成全站所有页面的流量埋点。

---

## 一、获取 Google Analytics 衡量 ID (Measurement ID)

1. 登录 [Google Analytics 官方控制台](https://analytics.google.com/)。
2. 点击左下角的 **管理（Admin）** 图标。
3. 在 **媒体资源（Property）** 列中，点击 **创建媒体资源（Create Property）**，填写网站名称、时区和币种。
4. 业务信息填写完毕后，选择收集数据的平台为 **网站（Web）**。
5. 填写您的网站 URL（例如 `https://yishulun.com`）和信息流名称（如 `艺述论博客`）。
6. 创建完成后，系统将展示该网站的数据流详情，复制右上角的 **衡量 ID（Measurement ID）**，格式通常为：
   `G-8N64Q25EK9`

---

## 二、在 RustPress 中启用与配置

打开您的 `config.toml` 文件，找到或添加以下两个配置块：

```toml
# 1. 开启全局分析开关
[features]
analytics = true

# 2. 配置 Google Analytics 媒体资源 ID
[analytics]
google_id = "G-8N64Q25EK9"
```

---

## 三、底层模板注入原理

当 `features.analytics = true` 且 `analytics.google_id` 不为空时，RustPress 会在所有生成的 HTML 页面（通过 `themes/default/templates/base.html` 或 `themes/light/templates/base.html`）的 `<head>` 区域自动注入标准的 Google gtag 跟踪代码：

```html
<!-- Google Analytics (GA4) -->
{% if features.analytics and analytics.google_id %}
<script async src="https://www.googletagmanager.com/gtag/js?id={{ analytics.google_id }}"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', '{{ analytics.google_id }}');
</script>
{% endif %}
```

> **优势**：
> - 采用 `async` 异步加载，完全不阻塞页面渲染与核心 Web 关键指标（Core Web Vitals）。
> - 纯配置驱动，更换主题或更新页面结构时无需手动重新粘贴脚本。

---

## 四、验证统计是否生效

### 1. 浏览器开发者工具检查
在浏览器中打开已部署上线的博客，按 `F12` 打开开发者工具：
- 切换到 **Network（网络）** 标签页，在过滤器中输入 `gtag` 或 `collect`。
- 刷新页面，查看是否成功向 `google-analytics.com` 发送了带有当前 URL 的状态码 200/204 数据收集请求。

### 2. Google Analytics 实时报告（Realtime Report）
打开 Google Analytics 控制台，进入 **报告 -> 实时（Realtime）** 面板。此时您在博客上浏览任何文章，控制台将在 5 秒内显示当前活跃用户数、所在城市以及正在访问的具体文章路径。

至此，您的独立博客已成功接入专业的全球流量监控系统！
