# 专栏与分类法路径配置

在现代网站架构与搜索引擎优化（SEO）中，**短小、语义清晰且层级结构规范的 URL 路径**能够显著提升用户体验和搜索引擎爬虫权重。

RustPress 提供了强大的 **`[taxonomies]` 分类体系与路由映射机制**，允许创作者自由定义专栏、闲言、标签、分类、项目、著作与归档的对外 URL 别名。

---

## 一、`[taxonomies]` 默认映射表与配置

打开 `config.toml`，找到 `[taxonomies]` 配置区块：

```toml
# ==============================================================================
# 分类法与内容体系 URL 路由别名映射 [taxonomies]
# ==============================================================================
[taxonomies]
columns = "/c"        # 专栏体系（系列长文/连载课程）
tweets = "/t"         # 短动态（闲言碎语/去中心化微博）

categories = "/cat"   # 文章分类体系
tags = "/tag"         # 标签云体系

projects = "/p"       # 个人开源项目与软件作品
works = "/w"          # 个人出版著作与书籍

archives = "/a"       # 历史按年份月份归档
friends = "/f"        # 友情链接页面
about = "/about.html" # 个人作者简介独立页
```

---

## 二、核心内容模型的 URL 生成规则

当您在 `config.toml` 中配置了上述路由规则后，RustPress 在静态编译时会自动映射生成对应的目录与 URL：

| 内容模型 | 源码存放目录 | 路由配置项 | 最终对外访问 URL 示例 |
| :--- | :--- | :--- | :--- |
| **专栏总览** | `source/columns/` | `columns = "/c"` | `https://yishulun.com/c/` |
| **单个专栏** | `source/columns/rustpess/` | `columns = "/c"` | `https://yishulun.com/c/rustpess/` |
| **专栏文章** | `source/columns/rustpess/1.1.md` | `columns = "/c"` | `https://yishulun.com/c/rustpess/1.1.安装与本地开发预览.html` |
| **短动态闲言** | `source/tweets/` | `tweets = "/t"` | `https://yishulun.com/t/` |
| **全站分类** | `source/` 目录结构 | `categories = "/cat"` | `https://yishulun.com/cat/` |
| **单分类列表** | 文章 Frontmatter | `categories = "/cat"` | `https://yishulun.com/cat/后端/` |
| **全站标签** | 文章 Frontmatter | `tags = "/tag"` | `https://yishulun.com/tag/` |
| **单标签列表** | 文章 Frontmatter | `tags = "/tag"` | `https://yishulun.com/tag/Rust/` |
| **个人项目** | `source/projects/` | `projects = "/p"` | `https://yishulun.com/p/` 或 `/p/rustpress.html` |
| **出版著作** | `source/works/` | `works = "/w"` | `https://yishulun.com/w/` 或 `/w/miniprogram-0-1.html` |
| **历史归档** | `source/` 时间轴 | `archives = "/a"` | `https://yishulun.com/a/` |
| **友情链接** | `source/friends/` | `friends = "/f"` | `https://yishulun.com/f/` |

## 三、与顶部导航菜单（`menu.main`）协同

修改了 `[taxonomies]` 的路径别名后，应确保 `[[menu.main]]` 导航菜单中的链接与其保持一致：

```toml
[[menu.main]]
name = "首页"
url = "/"
weight = 1

[[menu.main]]
name = "归档"
url = "/a/"
weight = 2

[[menu.main]]
name = "分类"
url = "/cat/"
weight = 3

[[menu.main]]
name = "标签"
url = "/tag/"
weight = 4

[[menu.main]]
name = "专栏"
url = "/c/"
weight = 5

[[menu.main]]
name = "友链"
url = "/f/"
weight = 6

[[menu.main]]
name = "项目"
url = "/p/"
weight = 7

[[menu.main]]
name = "关于"
url = "/about.html"
weight = 8
```

在 light theme 中没有导航，但在 default theme 中有顶部导航。

## 四、个性化定制建议

- **偏好长语义**：如果您希望与传统的 Hugo/Hexo 风格一致，可以改为：
  `columns = "/columns"`, `categories = "/categories"`, `tags = "/tags"`, `archives = "/archives"`。
- **偏好极简极速**：保留默认的单字母缩写（`/c`, `/cat`, `/tag`, `/p`, `/w`, `/a`, `/f`），URL 短小精干，在移动端与社交平台展示更具有优势。
