# 开源项目 (Projects) 展示与管理

独立开发者通常拥有许多开源工具、客户端程序、Web 应用或 CLI 命令行工具。RustPress 专门提供了 **项目展示模型（Projects）**，让您能够以类似 App Store / 软件官网的优雅版式展示自己的作品。

---

## 一、项目目录结构规范

每个项目在 `source/projects/<project_name>/` 下以独立子目录维护：

```text
source/projects/
├── README.md                 # 项目库总览页
├── rustpress/                # 项目 1 目录
│   ├── README.md             # 项目详情与元数据（核心）
│   └── assets/
│       ├── rustpress_logo.png
│       └── screenshot1.png
└── enyan/                    # 项目 2 目录
    ├── README.md
    └── assets/
```

---

## 二、项目 `README.md` 元数据与排版规范

在项目子目录下创建 `README.md`，其标准 Frontmatter 如下：

```yaml
---
title: "RustPress - 纯静态博客引擎"
layout: project
version: "0.1.21"
description: "增量编译、倒分页、无后端的 Rust 纯静态博客系统。支持 Markdown 写作、主题定制与热重载。"
createTime: 2026-02-19 15:00:00
icon: "assets/rustpress_logo.png"
screenshots: []
downloads:
  - platform: "Cargo 一键安装"
    url: "https://crates.io/crates/rustpress"
    icon: "link"
    size: "cargo install rustpress"
  - platform: "源码仓库 (GitHub)"
    url: "https://github.com/rixingyike/rustpress"
    icon: "github"
    size: "Star / Fork"
tags: ["rust", "blog", "static-site", "ssg", "开源"]
comments: false
toc: true
---

## 功能特性

- ⚡ **毫秒级增量编译**：仅重新编译变更文件，构建瞬间完成。
- 🔄 **独创倒分页算法**：历史分页内容与 URL 永久固化，SEO 极致友好。
- 🎨 **现代化主题体系**：基于 Tera + Tailwind CSS，极速热重载。
- 🔍 **客户端全文检索**：内置 Lunr.js，无需任何后端服务器。

## 快速开始

```bash
cargo install rustpress
rustpress new my-blog
cd my-blog && rustpress serve
```

## 开源协议

MIT License
```

### 属性字段说明表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | `String` | 项目名称。 |
| `layout` | `String` | 固定指定为 `project`。 |
| `version` | `String` | 当前软件版本号（如 `0.1.21`），会在页面顶部以徽章展示。 |
| `icon` | `String` | 项目 Logo 图标路径。 |
| `downloads` | `Array` | 多平台下载渠道/安装命令数组，支持配置按钮文本、URL 及安装指令。 |
| `tags` | `Array` | 技术标签（如 `Rust`, `WebAssembly`）。 |
| `screenshots`| `Array` | 软件截图轮播数组。 |

## 三、项目展示效果

- **项目汇总页（`/p/`）**：网格式展示所有开源项目卡片，显示 Logo、项目名、当前版本徽章与简要介绍。
- **项目独立页（`/p/rustpress.html`）**：顶部呈现清晰的软件信息头与一键下载/安装按钮组，正文呈现功能特性、架构图谱、安装教程与开源协议。
