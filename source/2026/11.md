# 社区终端软件支持 brew 安装了

现在有两种安装方式，老方法去 GitHub 下载：

[https://github.com/rixingyike/homebrew-setalias/releases](https://github.com/rixingyike/homebrew-setalias/releases)

新方法就是使用 brew 指令：

```
brew tap rixingyike/setalias
brew install setalias
```

除了安装方式上的更新，本次更新还把 Python3 依赖项在 install 时整合在了一起，让用户一键拷贝安装。

下一步，我准备加一个 UI 界面，将环境变量的设置放在界面上。是不是有了界面感觉会容易一些？另外，准备支持 Windows、Linux。本来就是一个跨平台的脚本软件，支持这两个系统是应该的。还有，如果可以，我想精简一下依赖项。像有一些依赖，比如 OpenAI，去掉也可以，只用了里面的某个代码片段，自己重写也可以。

另外，从长远来看，我觉得未来 Rust+Bash 很有前途，Rust 是可以编译的，本身支持跨平台。Bash 脚本也是跨平台的。Bash 写胶水代码，Rust 可以写核心代码，将某些关键逻辑封装起来，不让别人看到。
